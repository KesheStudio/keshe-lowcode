站内检索演示

构建期把页面变成 search-index.json，运行时只加载一个 JS 和一个 CSS。 这一页把索引直接内联在 HTML 里，所以用 file:// 双击打开也能搜。

键盘：上/下方向键 选择，回车 跳转， Esc 关闭。中文输入法组合期间不会触发搜索。

强缓存与 Cache-Control

浏览器缓存分强缓存和协商缓存。强缓存由 Cache-Control 的 max-age 控制，命中后连请求都不发。静态资源适合长 max-age 加文件名哈希，HTML 用 no-cache 保持可更新。

协商缓存 ETag

协商缓存把 ETag 或 Last-Modified 发给服务器，由服务器判断是否返回 304。只省传输不省往返，所以别指望它替代强缓存。

倒排索引的结构

倒排索引把词映射到文档编号列表，查询时按词取出候选文档再打分，不需要逐篇扫描全文。词典保存词和倒排表位置，倒排表保存文档编号、词频和可选的位置信息。

倒排表与增量合并

增量更新通常先写小段再合并，删除用标记位延迟清理。位置信息决定能不能做短语查询，代价是索引变大。

二字切分与单字回退

中文没有空格，索引前必须先切分。轻量方案按连续汉字切成二字组合，同时保留单字，不用维护词典，代价是会出现一些无意义组合。

停用词与标点处理

停用词只过滤单字和英文整词，双字组合保留，避免误杀可用、上游这类技术词。标点先归一化再切分。

BM25 与 idf

排序要把稀有词看得更重，idf 就是干这个的。词频不能无限加分，BM25 用饱和函数压住长文档的优势。标题命中比正文命中更重要，可以用字段权重，也可以按标题、章节、正文分组展示。

Vite 与依赖图

构建工具从入口解析 import，形成依赖图，再决定哪些模块进同一个包。代码分割让首屏只加载需要的部分，其余按需请求。

Bundling 与产物体积

产物体积要看压缩前、gzip 后和实际传输三个数字。第三方库通常占大头，先看分析报告再决定拆包。

Nginx 反向代理

静态站点用 Nginx 直接托管最省事，反向代理把接口请求转给后端进程。回滚要保留上一版产物和配置，出问题能在几分钟内切回去。

证书与 HTTPS

HTTPS 证书有有效期，过期当天所有请求都会失败，续期和到期提醒要写进发布流程。

事务与 MVCC

事务把多条写操作打包成一个整体，要么全部成功，要么全部回滚。MVCC 用版本链和快照读避免读写互相阻塞。

隔离级别与死锁重试

死锁通常来自两个事务以相反顺序锁同一批行，应用层要能识别并重试。长事务会拖住清理线程，排查时同时看事务持续时间和锁等待。

火焰图与 profiler

性能问题先测量再动手，没有基线的优化很容易花在无关紧要的地方。火焰图横向宽度代表占用时间，纵向代表调用栈，最上面宽而平的那段通常是热点。优化后用同一份数据和同一套环境复测，才能判断收益来自代码还是机器。

日志、指标与链路追踪

日志回答发生了什么，指标回答整体趋势，链路追踪回答一次请求经过了哪些服务。日志要结构化，至少带时间、级别、请求标识和关键业务字段。全量采集链路成本很高，通常按错误、慢请求和固定比例采样。

键盘操作与焦点管理

所有可点击元素都要能通过键盘到达，Tab 顺序和视觉顺序一致。弹窗打开后焦点进入弹窗，关闭后回到触发按钮。不要直接 outline none，换成内外两层焦点环。

颜色对比度

正文和背景对比度至少 4.5 比 1，暗色主题要单独检查。上面的搜索框和命中高亮在亮暗两套主题里都沿用了同一组颜色令牌。

JWT 与刷新令牌

认证回答你是谁，授权回答你能做什么。JWT 适合无状态校验，但撤销困难；刷新令牌可以轮换并落库，用来弥补这一点。密码只能用带盐的慢哈希保存，bcrypt、scrypt 或 Argon2 都可以。

语义化版本与发布清单

语义化版本用主版本表示不兼容变更，次版本表示新增功能，修订号表示修复。发布清单至少覆盖构建产物、配置、数据库迁移、证书和回滚包。数据库迁移尽量向前兼容，否则代码能回滚、数据回不去。
