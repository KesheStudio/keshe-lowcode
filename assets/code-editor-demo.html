无障碍与焦点

  • 键盘可达：Tab 可进入查找框、匹配计数、上一个/下一个、正则、大小写和关闭按钮；Esc 关闭后焦点回到编辑区。
  • 键盘边界：编辑区内 Tab 用于缩进（代码编辑器惯例），不用于切换焦点；查找栏打开后 Tab 在控件间移动，Esc 回到编辑区。
  • 焦点可见：整块编辑器用 :focus-within 显示边框和 2px 光晕；输入框、复选框、按钮用 :focus-visible 显示 outline。
  • 可读名称：textarea 的 aria-label 随语言更新（例如「代码编辑器（JavaScript）」），并声明 aria-keyshortcuts="Control+S Control+F Control+H"；查找、替换、计数、关闭按钮都有各自的 aria-label。
  • 结果播报：查找无结果、正则无效、替换结果、括号未配对、大文件降级都写入 role="status" aria-live="polite" 区域，读屏会读出「无结果（已搜索全文 N 行）」这类完整信息。
  • 行号栏和装饰层对读屏隐藏（aria-hidden），避免逐行重复朗读；行列与选中字符数在状态栏文本里。

外部接管容器时的注意事项

  • 高度：容器必须有确定高度，例如 height: 520px，或在 flex 布局里写 flex: 1; min-height: 0。编辑器自身是 height: 100% 且最小 220px；父级高度为 auto 时会退到最小高度，行号窗口和滚动范围都按这个高度算。
  • 字体继承：编辑区固定使用 --lc-font-mono，行高固定为 --lce-line-height（默认 20px）。外部不要再给 textarea 或高亮层单独设 font-size / line-height；要改字号请覆盖 --lce-font-size 并同步改 --lce-line-height，两者不匹配会让光标和高亮错位。
  • z-index：编辑器根节点已经是 position: relative 并建立了独立层叠上下文（isolation: isolate），内部层级固定在 0/1/2。宿主的下拉菜单、拖拽把手不要插进 .lce-code；需要和弹窗比较层级时，给编辑器外层容器设 position 与 z-index，不要改内部层级。
  • 多实例共存：每个实例有独立的 DOM、定时器和唯一 id（lce-help-*、lce-find-msg-*），快捷键监听挂在各自根节点上，只有焦点所在实例响应。卸载时调用 destroy()，它会移除全局 selectionchange 监听和括号匹配定时器；不要只删 DOM 节点。
  • 主题：所有颜色来自 --lc-color-*，跟随最近的 [data-lc-mode="dark"] 或 [data-theme="dark"] 祖先；多个实例默认共享页面主题，也可以在外层容器上单独设 data-lc-mode 做局部主题。
  • 输入法：组合输入期间高亮层自动隐藏，文字交还 textarea；宿主不要在这段时间强制刷新 value。

tokenizer 已知局限

  • JavaScript 的正则字面量（/abc/g）不单独着色，里面的引号可能被误认成字符串。
  • 模板字符串整体按字符串着色，${...} 里的表达式不会再拆分。
  • 不支持 JSX、TypeScript；类型注解按普通标识符处理。
  • JSON 按严格 JSON 处理：注释、尾逗号、单引号都不属于合法语法，也不会特殊着色。
  • CSS 只覆盖基础选择器、属性名、数值/单位、十六进制颜色、函数与注释；SCSS/Less、原生 CSS 嵌套、复杂选择器不做语义分析。
  • HTML 只做标签名、属性名、属性值、注释、DOCTYPE 与实体的区分；<script> / <style> 内部不进入子语言。
  • Markdown 用行级规则判断标题、引用、分隔线、列表与围栏代码；行内只识别反引号代码、链接和 */_ 强调，复杂嵌套不做完整解析。
  • Rust / Go / Java 按 C 系规则着色，不做宏展开、泛型嵌套、类型推导；Rust 属性（#[...]）按普通符号处理。
  • 查找替换每次最多记录 10000 个匹配，超出后计数带 +；大文件模式下不画命中底色，但计数和替换仍然工作。
  • 括号匹配按语言跳过字符串、行注释、块注释、HTML 注释和 Java 文本块；JavaScript 模板字符串的 ${...} 内部被当作字符串，不参与匹配。
  • 超过 5,000 行进入大文件模式，括号匹配暂停，避免每次移动光标都扫描全文。

接入方式

// 页面先引入 lc-tokens.css、lc-code-editor.css 与 code-editor.js
const editor = LC.CodeEditor.create('#code-editor', {
  language: 'javascript',   // javascript | json | css | html | markdown | rust | go | java
  value: 'const a = 1;',
  tabSize: 4,
  maxHighlightLines: 5000, // 超过降级为纯文本；Infinity 关闭降级
  onChange(value, meta) { // 每次文本变化 },
  onSave(value) { // Ctrl+S 或编辑器实例 save() }
});

LC.CodeEditor.defaults.maxHighlightLines; // 5000
editor.setValue(next, { silent: true }); // 不触发 onChange
editor.openFind('find');   // 'replace' 打开替换行
editor.replaceAll();        // 返回替换处数
editor.destroy();           // 卸载：移除全局监听与定时器

容器需要有明确高度；编辑器会铺满容器。实例还提供 getValue / setValue / setLanguage / setTabSize / focus / destroy，以及 openFind / closeFind / findNext / findPrev / replaceOne / replaceAll / getFindState。
