服务已运行，但编辑器打不开？

  1. 确认地址栏端口与服务打印的一致（端口被占用时脚本会自动换端口）。
  2. 回到启动窗口看是否有“只读模式”提示；磁盘不可写时保存会被禁用。
  3. 仍不行就运行 npm run doctor，逐项看哪一条没通过。

服务没有启动

  1. 双击平台根目录的 start.cmd，或在平台根运行 npm start。
  2. 看启动窗口打印的地址，打开那个地址；不要再双击 index.html。
  3. 没有安装依赖时，启动脚本会自动执行 npm install；装不上按提示检查 npm 源。
  4. 端口被占用时脚本会自动换一个端口并打印出来，以打印地址为准。

常见失败对照

  • 配置损坏：启动窗口会列出具体字段；详细原因写进 logs/boot-error.json。
  • 磁盘不可写：服务仍会启动，但进入只读模式，编辑器顶部会常驻提示。
  • 端口占用：直接运行服务会明确报错；一键脚本会自动换端口。
  • 站点损坏：站点标记为待修复，只读浏览，先在 backups/ 里找备份。
