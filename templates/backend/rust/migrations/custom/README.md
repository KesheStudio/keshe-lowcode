# [LC-CUSTOM] 用户区：平台永远不会覆盖这个目录

放你自己的迁移脚本，文件名建议 `0003_add_xxx.sql`、`0004_xxx.sql`，按名称排序执行；生成的迁移全部执行完后再跑这里。

规则：

- 平台生成的迁移在 `../generated/`，重新生成会整块替换；你的脚本不要放那边。
- 版本号取文件名（去掉 `.sql`），记录在 `schema_migrations` 表；`generated/` 与 `custom/` 的文件名必须全局唯一，建议用连续编号。
- 不要修改已执行过的文件内容，要改就新增一个。
- 每条语句用分号结尾。迁移执行器按分号切分，SQL 字符串字面量里不要出现分号。
- 迁移在事务中执行，失败会整条回滚（MySQL 的 DDL 会隐式提交，失败后请手动清理残留表）。
- 需要回滚时，在 `../down/` 放一个同名文件（如 `0003_add_xxx.sql`），`--migrate-down` 只回滚「最新且有 down 文件」的一个版本。
