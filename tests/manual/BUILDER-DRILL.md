# Builder 手动演练记录

本文件记录 Builder 画布、保存链路、剪贴板与资源导入的可复现演练步骤与实测结果。
每次改动 Builder 相关代码后，按顺序重跑一遍；表格里的数值是当次实测值，复现时以"断言"列的结构性条件为准。

- 演练日期：2026-11-07 ~ 2026-11-08
- 环境：Windows + Node ≥ 20，Edge headless（CDP 驱动），服务 `npm run dev` 监听 `127.0.0.1:9780`
- 演练站点：`data/sites/builder`（演示站），页面 `home`
- 访问令牌：从 `GET /builder.html` 返回的 `<meta name="lc-token">` 读取；所有 `/api/*` 请求带 `x-lc-token`

## 0. 演练前确认

1. `npm run dev` 启动服务。
2. 打开 `http://127.0.0.1:9780/builder.html?site=builder&page=home`。
3. 页面应显示 5 个区块：
   - `drill-free`（`variant: "free"` 容器，`pos.height: 420`）
     - `drill-heading`（标题，`pos: 20/20/320/60`）
     - `drill-move`（段落，`pos: 120/170/400/180`）
   - `drill-flow-a`、`drill-flow-b`（两个流式段落）
4. 读取磁盘真值：
   `GET /api/sites/builder/builder/page?pageId=home` → `data.page.blocks`。

> 下列 rev 数值随演练历史递增，复现时只断言"rev 比操作前大"。

## 1. 自由定位容器：真实拖动与缩放

**步骤**

1. 在左侧图层树点 `drill-move`（段落），画布出现选中框与右下角缩放手柄。
2. 在画布内按住 `drill-move` 拖动，落到目标位置后松手。
3. 读取 `GET /api/sites/builder/builder/page?pageId=home`，检查 `blocks[0].blocks[1].pos.left/top`。
4. 拖右下角小方块改变尺寸，松手后再次读取 `pos.width/height`。
5. 刷新 Builder 页面（或点工具条"重新加载"），确认几何值保持不变。

**实测**

| 操作 | 操作前 | 操作后 | rev |
| --- | --- | --- | --- |
| 拖动 `drill-move` | left 20 / top 110 | left 120 / top 170 | 3 → 4 |
| 缩放 `drill-move` | width 320 / height 120 | width 400 / height 180 | 递增 |
| 刷新后 | — | 120 / 170 / 400 / 180 不变 | 保持 |

**断言**

- `pos.left/top` 与落点一致，且刷新后不回弹。
- `block.pos` 写在 `pages/home.json`，不是仅改画布样式。
- 相关实现：`assets/builder.js` 的 `bindCanvasDrag`、`bindStaticEvents`（拖动/缩放指针事件）。

## 2. 草稿恢复

**步骤**

1. 选中 `drill-heading`，在属性面板改标题文字，**1.2 秒内**刷新页面（自动保存尚未触发）。
2. 刷新后应出现横幅「发现本地草稿」，按钮为「恢复草稿 / 丢弃草稿 / 关闭」。
3. 点「恢复草稿」：属性面板回到草稿内容，状态栏提示"已恢复本地草稿，正在后台保存"，随后自动写盘。
4. 再改一次文字但不刷新，直接点「丢弃草稿」：回到磁盘版本，草稿被清除。
5. 再造一次草稿后点「关闭」：横幅隐藏，草稿仍留在 `localStorage`（下次打开仍会提示）。

**实测**

- 恢复草稿后 rev 5；恢复动作会自动保存，不需要再点保存。
- 丢弃后磁盘内容不变；关闭只隐藏横幅。
- 草稿键：`lc-builder-draft:<siteId>:<pageId>`，值含 `text/savedAt/rev`。
- 相关实现：`storeDraft/readDraft/restoreDraft/discardDraft`（`assets/builder.js`）。

**断言**

- 横幅标题为「发现本地草稿」，三个按钮均有响应（本次 2026-11-08 回归逐一点击验证）。
- 「恢复草稿」写盘成功；「丢弃草稿」加载磁盘最新版本。

## 3. 保存冲突（两个标签）

**步骤**

1. 同一浏览器开两个标签，都打开 `builder.html?site=builder&page=home`，都处于 rev 5。
2. 标签 A 改标题并保存 → 磁盘 rev 6。
3. 标签 B（仍持有 rev 5）改另一处并保存 → 服务端返回 409 `LC_E_REV_CONFLICT`。
4. B 出现对话框「这个页面在别处被改过」，提示"期望 rev 5，当前 rev 6"。
5. 点「用我的版本覆盖」：先 `GET` 最新 rev 再强制保存 → rev 7；点「放弃我的改动」则重新加载磁盘版本。

**实测**

- 冲突提示原文：「这个页面在别处被改过（期望 rev 5，当前 rev 6）」。
- 覆盖后内容以 B 的版本为准，rev 7。
- 相关实现：`saveNow` 的 409 分支 + `openConflictDialog`（`assets/builder.js`）；服务端写入入口 `PUT /api/sites/:id/file`。

**断言**

- 冲突不静默覆盖：未选择前磁盘保持 A 的版本。
- 覆盖路径会用最新 rev 重试，不再次冲突。

## 4. 剪贴板快捷键

**步骤**

1. 页面初始 5 个区块（见第 0 节）。
2. 选中 `drill-flow-a`，按 `Ctrl+C`，再按两次 `Ctrl+V` → 7 个区块。
3. 按 `Delete` → 6 个区块。
4. 按 `Ctrl+D`（复制一份）→ 7 个区块。
5. 按 `Ctrl+Z` → 6 个区块；`Ctrl+Shift+Z` / `Ctrl+Y` 可重做。

**实测**

`5 →（粘贴×2）7 →（Delete）6 →（Ctrl+D）7 →（Ctrl+Z）6`

**曾出现的 bug 与修复**

- 现象：顶层区块的复制/粘贴/删除/复制一份全部静默失败（画布与区块数无变化）。
- 原因：`listAtPath(path)` 对长度为 1 的顶层路径用 `blockAtPath([])` 找父级，返回 `null`。
- 修复：顶层直接返回 `page.blocks`（`assets/builder.js` 的 `listAtPath`，约 L212）。
- 修复后上述快捷键全部生效，并纳入 2026-11-08 回归（撤消/重做按钮与快捷键均通过）。

**断言**

- 每个操作后 `[data-block-count]` 与 `GET .../builder/page` 的区块数一致。
- `Ctrl+Z` 后撤销按钮可用、`Ctrl+Shift+Z` 后重做按钮可用。

## 5. 页面 / 组件库 / 模板库 拖入导入

**步骤**（三个板块各用一次拖入）

1. 页面板块：把 4 个文件同时拖入「拖入页面文件」区域：
   - `imp-a.page.json`（合法页面）
   - `imp-b.page.json`（合法页面）
   - `bad.txt`（格式不支持）
   - `huge.page.json`（601 KB，超过 512 KB）
2. 组件板块：拖入 1 个 `.component.json`。
3. 模板板块：拖入 1 个 `.template.json`。
4. 观察拖入时的高亮、进度条、日志、摘要与列表刷新；文件选择按钮另行点击验证。

**实测（2026-11-08）**

| 板块 | 拖入高亮 | 进度 | 摘要 | 日志 |
| --- | --- | --- | --- | --- |
| 页面（4 文件） | 有，drop 后清除 | 显示「正在导入 1/2」「2/2」 | 成功 2 个，未导入 2 个 / 共 4 个 | `bad.txt` 格式不支持；`huge.page.json` 体积超限 601 KB，上限 512 KB |
| 组件（1 文件） | 有 | 显示「正在导入 1/1」 | 成功 1 个，未导入 0 个 / 共 1 个 | 导入「导入组件」，列表出现 |
| 模板（1 文件） | 有 | 显示「正在导入 1/1」 | 成功 1 个，未导入 0 个 / 共 1 个 | 导入「导入模板」 |

补充：

- 文件选择按钮保留，走同一条导入管线；多文件可一次选多个。
- 重名时服务端自动改 id/路径/名称，并在日志里给出「页面 id 改为…」等说明。
- 体积上限 512 KB，超限返回 413 `LC_E_IMPORT_SIZE`；格式/结构不合法返回 422 `LC_E_IMPORT_FORMAT`，客户端按文件逐条提示。
- 相关实现：`handleImportFiles`（`assets/builder.js`）、`POST /api/sites/:id/builder/import`（`server/src/routes/builder.js`）。

**断言**

- 每个板块的放置区都有 `is-dragging` 高亮，drop 后清除。
- 校验失败的文件不阻断同批次其他文件。
- 完成后摘要给出成功/未导入计数，列表自动刷新。
