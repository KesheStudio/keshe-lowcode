# 07 后端积木：拖节点搭流程、生成三种语言

> 本篇目标：会在 `backend-flow.html` 里拖节点搭一个接口，知道每种节点怎么填、三种目标语言哪些能用哪些暂未开放，并能生成、预览、测试，最后在 Builder 里把页面事件接上来。
>
> 这是全手册里概念最多的一章。建议先照着第二节做一个「读集合 → 返回 JSON」的流程，再回头看节点参考。

---

## 一、先认清界面

打开 Builder 顶栏「后端代码」，或工作台进入站点后点「后端积木」，进入 `backend-flow.html`。

界面分四块：

| 区域 | 内容 |
| --- | --- |
| 顶栏 | 站点下拉、目标语言（Node / Rust / Go）、保存状态、载入示例、保存、校验、生成、启动预览、停止预览 |
| 左侧 | 节点库，带搜索框 |
| 中间 | 流程名称/版本/哈希、节点树、请求测试、生成结果 |
| 右侧 | 四个标签：节点属性、中间件、配置中心、组件库 |

底部状态栏会显示当前目标语言和生成区/用户区的分离说明。

几个关键概念：

- **节点树**：流程的执行顺序。入口节点决定方法和路径，后续节点按树顺序执行。
- **生成区**：平台根据节点树生成的代码。重新生成会覆盖。
- **用户区**：你写的代码，放在 `src/custom/`。重新生成**不会**覆盖。
- **目标语言**：本次生成翻译成 Node、Rust 还是 Go。它和新建项目时选的后端语言不是同一个设置。

## 二、做一个最小流程

### 第 1 步：选站点和目标语言

顶栏「站点」确认选对；「目标语言」第一次先用 `Node`。

### 第 2 步：点「载入示例」（可选）

想快速看结构，点顶栏「载入示例」。它会生成一个示例流程：

```text
HTTP 入口 → CORS → 日志 → 读取集合 items → 返回 JSON
```

不载入示例也可以从默认流程开始，默认是：

```text
GET /api/example → 返回 JSON
```

### 第 3 步：改「HTTP 入口」

点树里的入口节点，右侧「节点属性」出现：

| 字段 | 填什么 |
| --- | --- |
| 方法 | GET / POST / PUT / PATCH / DELETE |
| 路径 | 必须以 `/` 开头，例如 `/api/items` |
| 参数校验 | 可加多行参数，每行填参数名、位置、类型、是否必填 |

规则：

- 同一流程只能有**一个启用的入口节点**；
- 路径不支持查询串和空格；
- 参数校验在进入处理节点前执行，缺必填参数直接返回 400。

### 第 4 步：拖入「读取集合」

1. 左侧节点库展开「数据读写」；
2. 按住「读取集合」拖到中间节点树的合适位置；
3. 松手后节点插入；
4. 点它，在右侧填：

```text
集合 ID       items
页码          {{request.query.page}}
每页条数      {{request.query.pageSize}}
关键字        {{request.query.q}}
排序          createdAt:desc（可留空）
字段投影      id,title（可留空）
输出变量      rows
```

集合 ID 必须是当前站点里真实存在的集合（在数据源页面建，见第 06 章）。

### 第 5 步：改「返回 JSON」

点返回节点，填：

```text
状态码   200
响应体   {
  "items": "{{rows.items}}",
  "total": "{{rows.total}}"
}
响应头   {}
```

`{{...}}` 会被替换成真实值。响应体必须是合法 JSON 模板。

### 第 6 步：点「保存」

顶栏「保存」或 `Ctrl+S`。保存状态徽标变成「已保存」。

### 第 7 步：点「校验」

校验会检查：

- 是否有启用的入口；
- 路径格式；
- 必填参数是否填了；
- 集合是否存在；
- 目标语言是否支持所有节点；
- 容器节点是否为空；
- 表达式是否为空等。

有问题会列在结果区，按提示逐条修。

### 第 8 步：点「生成」

生成成功后出现「生成结果」卡片：

- 显示目标语言、流程哈希、生成时间；
- 列出生成的文件路径和大小；
- 提示哪些文件在生成区、哪些在用户区。

生成只写生成区。你在 `src/custom/` 下的代码不会被动。

### 第 9 步：启动预览并测试

1. 点「启动预览」；
2. 等状态变为已启动（首次启动需要构建，Rust / Go 目标更慢）；
3. 在「请求测试」里填路径，例如 `/api/items`；
4. 非 GET 可填 JSON 请求体；
5. 点「发送」；
6. 下方显示状态码、耗时、响应内容。

预览同一站点同一语言只保留一个实例，重复启动会先停掉旧的。停止用「停止预览」。

## 三、节点库与拖拽规则

节点库按类别分组：

```text
入口         HTTP 入口
中间件       CORS、鉴权、限流、日志
数据读写     读取集合、写入集合、读取文件、写入文件、外部 HTTP
数据处理     数据变换
流程控制     条件分支、循环
响应         返回 JSON
后端组件     自定义组件
用户代码     用户代码
```

操作规则：

- 按住节点拖进中间节点树；
- 拖到**容器节点的中间**会嵌套进去；容器的槽位有「满足条件」「否则」「循环体」；
- 拖到普通节点之间按顺序插入；
- 拖动时按 `Esc` 取消；
- 节点库上方有搜索框，按名称过滤；
- 树工具栏有「展开全部」「收起容器」；节点计数显示在右上。

中间件的执行顺序不受拖放位置影响，而是按固定安全顺序：

```text
CORS → 日志 → 鉴权 → 限流
```

## 四、节点属性怎么填

选中节点后，右侧「节点属性」按 schema 生成字段，通常包含：

- `节点名称`：显示用，可改；
- `启用`：取消勾选后节点保留但不参与执行和生成；
- `节点 ID`：只读，稳定不变；
- 该节点自己的字段。

字段类型：

- 文本、数字、下拉、开关；
- 多行文本（JSON 时必须是合法 JSON）；
- 表达式字段，支持 `{{...}}`。

### 表达式写法

可引用的常见变量：

```text
{{request.query.page}}
{{request.query.q}}
{{request.body}}
{{request.params.id}}
{{request.headers.authorization}}
{{rows.items}}
{{rows.total}}
{{item.title}}
{{loopItems}}
```

规则：

- 表达式用双大括号包住；
- 支持比较与逻辑运算，例如：

```text
{{rows.total > 0 && request.query.debug !== "1"}}
```

- 字符串里的表达式在 JSON 模板中会被替换成值；
- 变量不存在时按空值处理，不会让整个流程崩溃。

### 输出变量

大部分数据节点都有「输出变量」，命名规则：

```text
小写字母开头，只含字母、数字、下划线，最多 32 个字符
```

后续节点用 `{{变量名.字段}}` 引用。变量名建议语义化，例如 `rows`、`created`、`file`。

## 五、节点参考

下面按类别列出当前版本真实存在的节点。没有列出的节点，就是当前版本没有。

### 入口

| 节点 | 作用 | 关键字段 |
| --- | --- | --- |
| HTTP 入口 | 方法 + 路径 + 参数校验 | 方法、路径、参数校验 |

### 中间件

| 节点 | 作用 | 关键字段 |
| --- | --- | --- |
| CORS | 跨域响应头与 OPTIONS 预检 | 允许的来源（逗号分隔）、允许携带凭证、预检缓存 |
| 鉴权 | 登录校验 + 角色白名单 | 允许的角色（留空表示登录即可） |
| 限流 | 令牌桶，按 IP 或令牌限速 | 每秒补充、桶容量、限流键 |
| 日志 | 记录方法、路径、状态码、耗时 | 日志级别、跳过健康检查 |

注意：

- CORS 的「允许的来源」全为 `*` 且开启凭证时，校验会拒绝；
- 限流的「限流键」选 `token` 时取 Authorization 头的摘要，不存原文；
- 鉴权依赖后端鉴权服务，纯静态项目没有可用的鉴权来源。

### 数据读写

| 节点 | 作用 | 关键字段 |
| --- | --- | --- |
| 读取集合 | 按页读取集合行，输出 `{ items, total }` | 集合 ID、页码、每页条数、关键字、排序、字段投影、输出变量 |
| 写入集合 | 把对象写入集合，输出新行 | 集合 ID、写入内容、输出变量 |
| 读取文件 | 读取 `data/files` 下的文件 | 文件路径、编码（utf8 / base64）、输出变量 |
| 写入文件 | 写入 `data/files` 下的文件 | 文件路径、写入内容、追加写入 |
| 外部 HTTP | 调用外部接口，输出 `{ status, data }` | 方法、地址、请求头、请求体、超时、输出变量 |

当前**没有**「更新集合」「删除集合」积木。需要改行或删行时：

- 用「用户代码」节点写 Node 代码；
- 或者在外部接口 / 后端组件里处理。

这是当前版本的限制，不要按“增删改查都有积木”来排期。

外部 HTTP 的限制：

- 只允许 `http` / `https`；
- 禁止本机与内网地址；
- GET / HEAD 忽略请求体；
- 超时范围 100～60000 毫秒。

### 数据处理

| 节点 | 作用 | 关键字段 |
| --- | --- | --- |
| 数据变换 | 挑字段或按模板重组 | 方式（pick / template）、输入数据、保留字段、输出模板、输出变量 |

`pick` 只保留指定字段；`template` 按 JSON 模板拼装，模板里的 `{{…}}` 会替换成真实值。

### 流程控制

| 节点 | 作用 | 关键字段 |
| --- | --- | --- |
| 条件分支 | if / else 两棵子树 | 条件 |
| 循环 | 遍历数组，可收集结果 | 数据源、当前项变量、最大次数、收集表达式、输出变量 |

条件分支有两个槽位：「满足条件」「否则」。

循环的限制：

- 数据源必须是数组，非数组按空数组处理；
- 最大次数 1～1000，超出部分截断，避免死循环；
- 收集表达式每轮追加到输出数组，留空则收集当前项。

### 响应

| 节点 | 作用 | 关键字段 |
| --- | --- | --- |
| 返回 JSON | 状态码 + 响应体 + 响应头 | 状态码、响应体、响应头 |

当前**只有**「返回 JSON」一种响应节点，没有「返回文本」「重定向」「返回文件」积木。需要其它响应形态时，用用户代码节点自己写。

### 后端组件

| 节点 | 作用 | 关键字段 |
| --- | --- | --- |
| 自定义组件 | 引用后端组件库里的组件 | 组件、调用参数、输出变量 |

### 用户代码

| 节点 | 作用 | 关键字段 |
| --- | --- | --- |
| 用户代码 | 写入 `src/custom/handlers/`，生成过程不改写 | 代码语言、输出变量 |

点节点上的「编辑用户代码」打开代码对话框：

- 文件位于站点用户区 `src/custom/`；
- 顶部有「检查」「保存代码」「取消」「关闭」；
- 模板里 `run(ctx)` 的返回值写入该节点的输出变量；
- `ctx` 可拿到 `vars`、`request`、`reply`、`deps`。

## 六、三种目标语言：哪些能用，哪些暂未开放

在顶栏切换「目标语言」后，能力并不完全对等。当前真实情况：

| 节点 | Node | Rust | Go |
| --- | --- | --- | --- |
| HTTP 入口 | ✅ | ✅ | ✅ |
| CORS / 鉴权 / 限流 / 日志 | ✅ | ✅ | ✅ |
| 读取集合 / 写入集合 | ✅ | ✅ | ✅ |
| 读取文件 / 写入文件 | ✅ | ✅ | ✅ |
| 数据变换 | ✅ | ✅ | ✅ |
| 条件分支 / 循环 | ✅ | ✅ | ✅ |
| 返回 JSON | ✅ | ✅ | ✅ |
| 外部 HTTP | ✅ | ❌ 暂未开放 | ✅ |
| 自定义组件节点 | ✅ | ❌ 暂未开放 | ❌ 暂未开放 |
| 用户代码节点 | ✅ | ❌ 暂未开放 | ❌ 暂未开放 |

说明：

- 外部 HTTP 在 Rust 目标下**暂未开放**：Rust 服务模板没有 HTTP 客户端依赖，这是设计上不纳入，不是漏做；
- 自定义组件与用户代码节点的运行时装配目前只有 Node，Rust / Go 会明确报「组件 codegen 未接入」「代码节点未接入」；
- 页面级代码覆盖同样只对 Node 目标开放。Rust / Go 目标请在用户区自定义路由里实现；
- 校验会把不支持的节点标出来，不会静默跳过。

所以：

- 想用外部 HTTP、后端组件或用户代码，目标语言选 `Node`；
- 想生成 Rust / Go 骨架，避开这三类节点；
- 切换目标语言后重新点「校验」，不要直接生成。

## 七、校验、生成与用户区

### 校验

点「校验」会运行完整检查，结果按严重程度列出：

- 阻断性问题：生成会被拒绝；
- 警告：可以生成，但要确认影响。

常见阻断项：

- 没有启用的入口节点；
- 路径不以 `/` 开头；
- 集合不存在；
- JSON 字段不是合法 JSON；
- 条件分支/循环容器为空；
- 当前目标语言不支持某个节点。

### 生成

点「生成」后：

1. 先跑校验；
2. 通过后按目标语言生成服务端工程；
3. 写入生成区；
4. 显示「生成结果」，列出文件路径和大小。

生成不会改写 `src/custom/` 下的用户代码。

### 生成区和用户区

| 区域 | 路径 | 谁维护 | 重新生成 |
| --- | --- | --- | --- |
| 生成区 | `src/generated/` 等 | 平台 | 覆盖 |
| 用户区 | `src/custom/` | 你 | 保留 |

用户区包括：

```text
src/custom/handlers/     用户代码节点
src/custom/components/   后端组件实现
```

### 页面级代码覆盖（只在 Node 目标）

右侧「节点属性」下方有「页面级代码覆盖」卡片：

- 未覆盖时显示「跟随生成」；
- 点「覆盖页面代码」会在用户区创建入口文件，之后整段业务逻辑由你维护；
- 已覆盖时显示「已覆盖」，可点「编辑用户代码」；
- 「恢复原样」会删除用户区文件，让生成区重新接管；
- Rust / Go 目标下这张卡片显示「未开放」。

注意：这是**页面级**的覆盖，不是单个节点的用户代码。单个节点用「用户代码」节点。

## 八、请求测试与预览

### 启动预览

「启动预览」会把当前流程构建成一个真实服务并监听本机端口。

- 同一站点同一语言只保留一个预览实例；
- 启动前会自动保存当前流程；
- 首次构建可能较慢；
- 目标语言是 Rust 时需要本机有 `cargo`，Go 时需要 `go`；缺少工具链会启动失败并提示；
- 启动成功后，「请求测试」才可用。

### 请求测试

填：

- 请求路径，默认 `/api/items`；
- 请求体（仅非 GET，JSON）。

点「发送」后显示：

- 状态码与状态文本；
- 耗时；
- 响应内容（格式化后的 JSON 或文本）。

如果返回 404，先检查：

- 入口路径是否和测试路径完全一致；
- 预览是否真的启动成功；
- 生成是否在修改后重新执行过。

### 停止预览

点「停止预览」释放端口。关闭页面不会自动停止，养成手动停止的习惯。

## 九、后端组件库与作用域

右侧「组件库」标签用于管理**后端组件**，与前端组件库是两套东西。

### 新建组件

表单字段：

| 字段 | 说明 |
| --- | --- |
| 组件 ID | 小写字母开头，只含字母数字连字符，例如 `order-total` |
| 名称 | 显示用 |
| 作用域 | 「仅本项目」或「保存为全局」 |
| 支持语言 | Node / Rust / Go 多选 |
| 描述 | 可留空 |
| 参数 schema（JSON） | 每项 `{key,label,kind,required}`，节点属性面板按它渲染 |
| Node 实现 | 导出 `run(ctx, args)`；生成过程只引用不改写 |

### 作用域

| 作用域 | 存放位置 | 谁能用 |
| --- | --- | --- |
| 仅本项目 | 当前站点目录 | 只有当前站点 |
| 保存为全局 | 平台全局目录 | 所有站点都可复用 |

全局组件适合跨项目通用的逻辑，例如“计算订单总价”。项目内组件适合只服务当前站点的逻辑。

### 当前限制

- 表单只提供 **Node 实现**；
- 勾选 Rust / Go 只表示“能力矩阵里声明支持”，当前没有对应实现编辑器；
- 用 Rust / Go 目标生成时，引用组件的节点会报「组件 codegen 未接入」；
- 暂未开放的部分不要当成可用能力。

### 插入、编辑、导出、导入

每个组件卡片上有：

- `插入流程`：在当前选中位置插入一个「自定义组件」节点；
- `编辑`：把组件定义载入下方表单；
- `导出`：下载 `<组件ID>.component.json`；
- `删除`：二次确认，提示引用它的节点会变成悬空引用。

新建/编辑表单底部还有：

- `保存组件`；
- `导入 JSON`：把导出的 JSON 整段粘贴进来，确认后点「保存组件」。

### 在流程里使用组件

1. 点组件卡片的「插入流程」；
2. 选中「自定义组件」节点；
3. 「组件」下拉选具体组件；
4. 「调用参数」填 JSON，字符串里的 `{{…}}` 会先求值再传进去；
5. 「输出变量」供后续节点引用。

## 十、回到 Builder：把页面事件接上来

流程生成、预览通过后，页面还需要绑定事件才会调用它。

### 第 1 步：选中要触发事件的区块

在 Builder 画布或图层树里选中区块，例如一个按钮。

### 第 2 步：在「事件绑定」面板填

| 字段 | 填什么 |
| --- | --- |
| 事件 | click / submit / change / input / dblclick / keydown / keyup / focus / blur |
| 方法 | GET / POST / PUT / PATCH / DELETE |
| 后端积木接口 | 可从下拉选已有路径，也可手填，例如 `/api/items` |
| 返回处理 | 「自动写进指定组件」或「交给脚本处理」 |

选「自动写进指定组件」时，还要选「目标组件」：

- 数组 → 表格行；
- 数值 → KPI / 统计；
- 文本 → 文本组件。

选「交给脚本处理」时，填处理脚本，参数是：

```text
payload、data、event、root、target
```

例如：

```javascript
if (target) target.textContent = data.total;
```

### 第 3 步：点「添加绑定」

已绑定的事件会列在上方，显示摘要和「解绑」。

同一个区块可以绑多个事件；同一事件也可以重复绑定，但要注意执行顺序和覆盖关系。

### 绑定不生效时

按顺序检查：

1. 流程是否已「生成」；
2. 接口路径是否和绑定里的完全一致；
3. 预览是否启动（调试阶段）；
4. 导出产物是否包含后端（第 09 章）；
5. 返回值结构是否和目标组件匹配。

## 十一、常见问题

### 1. 为什么「生成」按钮点了没反应？

先看校验结果。有阻断项时生成会停在结果区，不会写文件。按提示修完再点。

### 2. 换了目标语言后节点变红？

该节点在当前语言下暂未开放。换回 Node，或删掉/替换该节点。

### 3. 预览启动失败，提示找不到 cargo / go？

本机没装对应工具链。装好工具链并确保在 PATH 里，或改用 Node 目标。

### 4. 用户代码会被重新生成覆盖吗？

不会。用户区 `src/custom/` 与生成区分离，生成只写生成区。但「恢复原样」会主动删除用户区文件。

### 5. 集合节点报「集合不存在」？

先去数据源页面建集合（第 06 章），并确认站点选对了。

### 6. 页面绑定了接口，为什么请求 404？

常见原因：

- 流程没生成；
- 入口路径拼错；
- 绑定的方法和入口方法不一致；
- 预览没启动；
- 导出时选了「无后端」。

### 7. 能在流程里更新或删除集合行吗？

当前没有对应积木。用「用户代码」节点写 Node 代码，或在外部接口里处理。Rust / Go 目标下用户代码节点暂未开放。
