# 科设低代码平台操作手册

这套手册面向**第一次接触科设低代码平台的人**。不要求会写代码，只要求能按步骤操作电脑。每一章都按「在哪个页面 → 点什么 → 填什么 → 会看到什么」来写，照做即可。

手册依据当前工作区 `lowcode/` 的真实界面与源码整理，不引用过时的设计稿结论。凡标有 **暂未开放** 的功能，当前版本确实不能按可用功能操作，请勿据此排期或交付。

---

## 阅读约定

- 按钮、菜单、标签页的名称用「」括起来，例如「新建项目」「保存」。
- 页面地址统一写作 `http://127.0.0.1:9780/`。如果你启动时端口被占用，以终端实际打印的地址为准。
- 文中说的「左侧」「右侧」均指浏览器窗口内的位置，不指文件目录。
- 手册不依赖截图：按文案找按钮即可。界面改版后，按钮位置可能微调，但名称通常不变。
- 需要看底层文件时，会写出相对路径，例如 `data/sites/<站点ID>/project.json`。

## 先认住四个地方

整套平台只有四个高频入口，先把名字记住：

1. **工作台**：`http://127.0.0.1:9780/`，项目列表。新建项目、进入编辑器、进入导出，都从这里出发。
2. **Builder（建站编辑器）**：点项目卡片进入。左边选页面和组件，中间是画布，右边改属性。
3. **资源页**：`组件库`、`模板库`、`数据源`、`中间件`、`配置中心`，都从顶部导航进入。
4. **导出向导**：把站点打包成 Web 静态包或桌面应用。导出入口在项目卡片和 Builder 顶栏都有。

---

## 读之前需要知道的边界

- 平台是**单机自用**：服务跑在你自己的电脑上，数据存在本地 `data/` 目录，不需要登录，也没有云端账号。
- 平台默认只监听 `127.0.0.1`，同一局域网的其他电脑默认访问不到。要给别人看，需要按第 10 章部署，或把导出产物放到服务器上。
- 「纯静态」和「带后端」是创建时定下的项目类型。当前界面**没有一键切换类型**的入口；选错通常只能新建项目，或改导出配置后重新导出。详见第 02 章。
- 画布是实时渲染的，没有独立的「预览」按钮。要看真实效果，用画布右上角的三档视口，或直接导出后打开产物。

## 遇到问题先做三件事

1. 看终端窗口最后 10 行。启动失败的原因和下一步动作通常已经打印出来。
2. 运行 `npm run doctor`。它会检查 Node 版本、依赖、数据目录可写性和端口占用。
3. 看 `logs/` 目录。启动失败会写 `logs/boot-error.json`；实际使用端口记录在 `logs/start-port.json`。

更细的排查顺序放在第 12 章。
