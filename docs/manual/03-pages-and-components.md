# 03 页面与组件：从空页到能用的版面

> 本篇目标：会在 Builder 里新建页面、插入区块、调整顺序与层级、改属性，并能在单个内置组件或自定义组件的实例上直接改 HTML / CSS / JS。
>
> 读完这一篇，你应该能独立把一个空白页排成有标题、正文、按钮和表单的页面，并知道每次改动存到了哪里。

---

## 一、先认清 Builder 的四个区域

打开项目后进入 Builder（地址形如 `builder.html?site=<站点ID>`）。界面固定分成四块：

| 位置 | 内容 | 用途 |
| --- | --- | --- |
| 顶栏 | 工作台、视口切换、站点下拉、保存状态、各类资源入口、撤销/重做、导出、保存 | 切站点、切视口、保存、跳转到其他功能页 |
| 左侧栏 | 「页面 / 组件库 / 模板库」三个标签 | 选页面、插入区块、套用模板 |
| 中间画布 | 当前页的真实渲染结果 | 点选区块、拖拽排序、自由定位时拖动与缩放 |
| 右侧属性面板 | 默认显示「页面属性」，选中区块后切成区块字段 | 改页面地址、尺寸，改区块内容和样式 |

几个容易忽略的细节：

- 顶栏的视口按钮是「桌面」「平板 820」「手机 420」。它们只改画布宽度，用来检查窄屏效果，不是真正生成三套页面。
- 画布不是截图，是实时渲染。改属性后画布会立刻重绘。
- 窄窗口下顶栏右侧会收进「更多 ▾」；左侧栏和属性面板会出现「资源」「属性」按钮来临时展开。
- 底部状态栏会显示「已与磁盘同步」或「有未保存改动（草稿已留存）」。自动保存在改动后约 1.2 秒触发，也可以按 `Ctrl+S` 立即保存。

## 二、新建页面

### 第 1 步：切到「页面」标签

左侧默认就在「页面」标签。如果不是，点「页面」。

### 第 2 步：点「新建页面」

按钮在「页面」标题右侧。点击后弹出「新建页面」对话框。

### 第 3 步：填「页面标题」

例如：

```text
产品介绍
```

对话框下方会实时显示将要生成的页面文件，例如：

```text
页面文件：pages/product-intro.json
```

命名规则：

- 标题只用英文和数字时，会转成小写连字符 ID，例如 `Product Intro` → `product-intro`；
- 标题含中文或无法转成英文时，自动生成 `page-1`、`page-2` 这样的 ID；
- ID 冲突会自动加 `-2`、`-3`；
- 标题不能为空，空着点「创建并编辑」会提示「请填写页面标题」。

### 第 4 步：点「创建并编辑」

按钮会短暂变成「创建中…」。成功后：

- 左侧页面列表多出一行；
- 画布切到新页面，显示空白；
- 右侧属性面板回到「页面属性」；
- 新页面默认字段是：标题为你填的文字、Slug 等于页面 ID、输出路径为 `<页面ID>.html`、「显示在导航」勾选。

如果页面文件已存在，会提示「页面标识「xxx」已存在，请换个标题」，不会覆盖旧文件。

### 页面列表怎么读

每一行显示三段信息：

```text
[PAGE] 产品介绍        product-intro.html
```

- 最左边 `PAGE` 表示「显示在导航」为开；如果显示 `OFF`，表示这个页面不进入导航；
- 中间是页面标题；
- 右边是输出路径。

点任意一行即可切换页面。切换前当前页的改动会先保存，不会因为切页丢失。

### 批量导入页面

「新建页面」下方还有一个「批量导入页面」，会打开单独的导入页 `page-import.html`。它适合一次导入多个已有 HTML / JSON 页面，不属于本章重点，按页面上的字段选择文件即可。

## 三、把区块放进页面

### 方式一：从「组件库」标签插入（推荐）

1. 左侧点「组件库」；
2. 找到「内置区块」分组，展开后是一串可插入的基础区块和 `ui-` 开头的内置组件；
3. 点某一项右侧的「插入」。

插入位置有一条约定的规则：

- 如果当前选中的是**容器**，新区块放进这个容器末尾；
- 其它情况（没选中、选中的是普通区块）一律追加到**当前页末尾**。

插入成功后会自动切回「页面」标签，并选中新插入的区块，右侧属性面板立刻变成它的字段。

### 方式二：从「组件库」标签插入自定义组件

同一个标签下方还有「组件库」分组，列出你保存过的自定义组件。点「插入」即可。自定义组件插入后是一个 `component` 类型的区块，字段值默认全空，需要你在属性面板里填。

### 空白页的提示

空白页中央会显示：

> 当前页还没有区块。到「组件库」点「插入」，或先导入一个页面。

这不是报错，只是提示。按上面的方式插入一个「标题」就能开始。

### 基础区块和内置组件的区别

| 类别 | 例子 | 属性面板里的代码覆盖 |
| --- | --- | --- |
| 基础区块 | 标题、段落、按钮、图片、卡片组、提示块、分隔线、代码块、文章列表、容器 | 没有「实例级代码覆盖」面板 |
| 内置组件（`ui-` 开头） | 输入框、滑块、表格、图表、标签页、上传等 | 有「实例级代码覆盖」面板，可改 HTML / CSS / JS |
| 自定义组件 | 你在组件库里做的组件 | 有「实例级代码覆盖」面板，另有「实例数据来源」面板 |

## 四、调整顺序与层级

### 在图层树里拖

左侧「页面」标签下半部分是「图层树」，标题右侧显示当前页区块总数。每一行显示：

```text
[类型徽标] 区块摘要        类型名
```

例如 `[H2] 标题：产品介绍 heading`。

操作方式：

- 点一行即可选中对应区块，画布同步高亮；
- 行首的 `▾` / `▸` 可以折叠或展开子区块；
- 直接拖动整行可以调整顺序；
- 把一行拖到**容器行的中间**，会嵌套进该容器；
- 拖动过程中按 `Esc` 取消，不会写入页面数据；
- 容器为空时，树里会显示「（空容器）」。

图层树支持多层嵌套，缩进表示层级。缩进越深，层级越深。

### 在画布里拖

普通流式布局下，画布里的区块可以直接拖动排序；拖动时会出现插入指示线。以下情况不能直接拖：

- 自由定位的子区块：需要在画布上按住拖动改位置，拖右下角小方块改尺寸；
- 正在编辑输入框等可编辑元素时，拖动会被让给输入操作。

落位后会重新渲染画布再检查一次布局：如果这次移动**新撑出了滚动条**（拖之前没有、拖之后有），平台会**直接回退到拖拽前的页面状态**——区块回到原位、这次移动的历史点被丢弃，撤销栈不会留下坏状态，同时提示「新位置会把页面撑出滚动条，已回退到拖拽前」。页面本来就有滚动条（长页面）不会触发回退。

### 选中与取消

- 点画布中的区块，或点图层树中的行，都会选中；
- 点画布空白处会取消选中，右侧回到「页面属性」；
- 键盘 `Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做。撤销/重做的按钮在顶栏。

## 五、右侧属性面板：页面属性

没有选中区块时，右侧标题是「页面属性」。字段逐项如下：

| 字段 | 说明 | 注意 |
| --- | --- | --- |
| 页面标题 | 显示在页面列表、导航和文档标题里 | 可随时改 |
| Slug | 页面短标识 | 一般与页面 ID 一致，改动会影响引用它的地方 |
| 输出路径 | 相对站点根的输出文件路径，例如 `product-intro.html` | 决定导出后文件放在哪 |
| 显示在导航 | 勾选表示这个页面参与站点导航 | 取消后页面列表徽标变成 `OFF` |
| 页面布局 | 「流式」或「自由定位」 | 自由定位时区块用 `pos.left/top` 摆放 |
| 最大宽度 | 页面根容器的 `max-width` | 留空表示不限 |
| 最大高度 | 页面根容器的 `max-height` | 留空表示不限 |

### 限宽限高的写法

只接受「数字 + 单位」的组合，单位可以是：

```text
px   vh   vw   %   rem
```

界面上建议：

- 最大宽度用 `px / vw / % / rem`，例如 `1200px`、`90vw`；
- 最大高度用 `px / vh / % / rem`，例如 `720px`、`80vh`。

合法示例：

```text
1200px
90vw
80vh
100%
48rem
```

非法示例（不会被写入）：

```text
abc
-10px
100
100 px
```

填了非法值时，输入框会标红，下方出现：

> 格式不正确：只接受数字 + px / vh / vw / % / rem，例如 720px；留空表示不限。

同时底部状态栏提示「页面尺寸格式不正确，本次没有写入」。修正后才会真正保存。

限高之后，超出内容会在页面内部滚动（渲染时自动加 `overflow:auto`），不会把整个画布撑破。画布预览和导出产物使用同一套规则。

### 自由定位模式

把「页面布局」切成「自由定位」后：

- 页面根容器里的区块按 `pos.left` / `pos.top` 绝对定位；
- 在画布上直接拖动区块可以改位置；
- 拖区块右下角的小方块可以改宽高；
- 位置会被夹在容器范围内，不会把页面撑出滚动条；
- 拖动时按 `Esc` 或拖出容器会取消，恢复拖动前的样式。

没有 `pos` 的旧区块不会全部叠在左上角，渲染时会按流式顺序向下排。

### 页面级代码覆盖（和实例级不是一回事）

「页面属性」下方还有两块高级功能：

1. **页面级代码覆盖**：`HTML / CSS / JS` 三个标签，作用范围是整页。
   - HTML 追加到页面末尾；
   - CSS 只作用域当前页；
   - JS 随页面脚本执行；
   - 内容随页面 JSON 保存，重新生成不会清掉。
2. **页面级接口覆盖**：只在当前页拦截指定 `METHOD + 路径` 的请求，先于站点后端与模板默认实现。日常搭页面用不到，接口细节放到第 07 章。

如果你只想改**某一个组件实例**，不要用这里，往下看「实例级代码覆盖」。

## 六、右侧属性面板：选中区块后

选中区块后，面板标题变成组件或区块名称，副标题显示 `类型 · 区块ID`。自上而下通常是：

1. **内容与样式**：按该区块的 schema 生成的字段；
2. **显示**：`区块可见` 复选框、只读的 `区块 ID`；
3. **实例级代码覆盖**（仅 `ui-` 内置组件与自定义组件）；
4. **事件绑定**；
5. **操作**：`复制一份`、`复制`、`删除`。

### 内容与样式

字段类型不同，控件也不同：

- 文本 → 输入框；
- 数字 → 数字输入框；
- 开关 → 复选框；
- 枚举 → 下拉框；
- 数组 / 对象 → JSON 文本框。

JSON 字段填错格式时，底部会提示「JSON 格式不合法，本次没有写入」，不会把坏数据存进页面。

### 显示

- 取消勾选「区块可见」后，画布里不再渲染这个区块，但数据和位置还在，重新勾选即可恢复；
- 「区块 ID」是只读的，用于事件绑定、实例脚本定位和代码覆盖，不要手改。

### 操作

- `复制一份`：在当前位置后面插入一个内容相同的区块，新 ID；
- `复制`：把区块 JSON 复制到剪贴板，便于备份；
- `删除`：从当前页移除。删除前请确认没有事件绑定还指向它。

## 七、单个实例直接改 HTML / CSS / JS（重要）

### 哪些区块能看到这个面板

选中以下两类区块时，属性面板会出现「实例级代码覆盖」：

- **内置组件**：类型以 `ui-` 开头的组件，例如滑块、输入框、表格、图表等；
- **自定义组件**：类型为 `component` 的区块。

基础区块（标题、段落、按钮、图片等）不显示这个面板。它们没有模板结构可以整段替换，只能改字段。

### 面板长什么样

标题是：

```text
实例级代码覆盖   [已覆盖]
```

下面是 `HTML` `CSS` `JS` 三个切换按钮，再下面是代码编辑器。按钮行里还有：

- `检查这一段`：对当前标签页的代码做语法检查，结果显示在编辑器下方；
- `载入组件默认`：只有自定义组件、且组件本身该标签页有内容时才出现，用来把组件默认代码填进编辑器；
- `恢复默认`：清除这个实例的覆盖，回到组件/内置默认渲染。

### 「已覆盖」徽标是什么意思

只要 `HTML`、`CSS`、`JS` 中**任意一项**有非空内容，标题旁就会出现蓝色的「已覆盖」徽标，`恢复默认` 按钮也会出现。

这个徽标是实时更新的：你在编辑器里输入第一行代码，徽标立刻出现；把三项都清空，徽标和按钮立刻消失。

它表示「这个实例与默认渲染不同」，不是错误。

### 三段代码各自怎么生效

| 标签 | 生效方式 | 作用范围 |
| --- | --- | --- |
| HTML | 非空时**整段替换**组件的默认结构 | 仅这个实例 |
| CSS | **追加**到页面样式，并限定在这个实例 | 仅这个实例 |
| JS | **追加**执行，包在独立作用域里 | 仅这个实例 |

具体约定：

- 内置组件留空 HTML 时按默认结构渲染；一旦填了 HTML，默认结构不再输出，需要你自己补齐需要的节点；
- CSS 不需要你手写实例前缀，渲染层会统一加作用域；
- JS 里可用 `root` 指向当前实例根节点，不要写 `window.xxx = ...` 之类的全局赋值；
- 禁止 `document.write` / `document.writeln` 和 `innerHTML` 拼接，保存和导出都会被拦截；
- 覆盖内容随**页面 JSON** 保存，重新渲染、刷新、导出都不会丢。

### 「恢复默认」到底恢复什么

点「恢复默认」只删除这个实例的 `HTML`、`CSS`、`JS` 三项覆盖，**不会**删除：

- 区块的字段值（例如标题文字、滑块的最小值）；
- 自定义组件的「实例数据来源」配置；
- 事件绑定。

所以恢复后区块还在，只是回到默认模板渲染。

### 和「页面级代码覆盖」的区别

| | 实例级 | 页面级 |
| --- | --- | --- |
| 入口 | 选中区块后的属性面板 | 不选区块时的「页面属性」 |
| 作用范围 | 一个区块实例 | 整个页面 |
| HTML | 整段替换该实例结构 | 追加到页面末尾 |
| CSS | 限定该实例 | 限定当前页 |
| 保存位置 | 页面 JSON 的区块 `overrides` | 页面 JSON 的页面 `overrides` |

### 一个建议的操作顺序

1. 先只用字段把内容填对；
2. 确认默认样式不够用时，再改 CSS；
3. 需要调整结构（例如加一层包裹、换标签）时才改 HTML；
4. 需要交互（例如动态显示、联动）时才写 JS；
5. 每改一段就点「检查这一段」，避免把语法错误留到导出时才暴露。

## 八、事件绑定（先知道在哪，细节看第 07 章）

属性面板的「事件绑定」面板用于把区块事件接到后端积木接口：

- 事件下拉：`click`、`submit`、`change`、`input`、`dblclick`、`keydown`、`keyup`、`focus`、`blur`；
- 方法下拉：`GET`、`POST`、`PUT`、`PATCH`、`DELETE`；
- 「后端积木接口」：可从下拉选已有路径，也可手填；
- 「返回处理」：`自动写进指定组件` 或 `交给脚本处理`。

已经绑定的事件会列在上方，显示摘要和「解绑」按钮。

这一节只帮你认位置。怎么在 `backend-flow.html` 里创建接口、返回值怎么映射，见第 07 章。

## 九、常见问题

### 1. 插入的区块为什么跑到页面最底部？

因为当前没有选中容器。`placeBlock` 的规则是：选中容器才放进容器，否则一律追加到页面末尾。想放进某个容器，先在图层树里选中那个容器，再点「插入」。

### 2. 为什么我拖不动某个区块？

两种常见原因：

- 页面或父容器是自由定位，子区块改用指针拖动和右下角手柄缩放，不走普通拖拽排序；
- 你正按在输入框、可编辑区域上，拖动被输入操作占用。

### 3. 改了「输出路径」，旧文件会怎样？

页面数据里只保存新路径，导出时按新路径生成。旧路径的产物不会自动保留。改路径前先确认没有别的页面或导航引用旧地址。

### 4. 实例代码改了，为什么画布没变化？

检查三点：

- 是否在正确的标签页输入（HTML / CSS / JS）；
- HTML 非空会整段替换默认结构，可能把可见节点删掉了；
- JS 报错不会阻止保存，但会让交互失效。点「检查这一段」看结果。

### 5. 「已覆盖」徽标能关掉吗？

它不是开关，是状态。把 `HTML`、`CSS`、`JS` 三项都清空，或者点「恢复默认」，徽标就会消失。

### 6. 页面限高后，内容被截断了吗？

没有。限高会加 `overflow:auto`，超出部分在页面内部滚动。导出后行为一致。
