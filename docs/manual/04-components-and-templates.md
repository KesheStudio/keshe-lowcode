# 04 组件库与模板库：复用、作用域与导入导出

> 本篇目标：会把自己的页面结构存成组件和模板，理解组件作用域为什么不会污染页面，能把组件/模板导出成 JSON 再导入回来或拖进编辑器。
>
> 组件库与模板库都是独立页面，从工作台顶栏或 Builder 顶栏进入。它们操作的是**当前选中的站点**，先确认顶栏「站点」下拉没有选错。

---

## 一、组件库和模板库分别解决什么问题

| | 组件库 | 模板库 |
| --- | --- | --- |
| 复用单位 | 一个可插入的区块 | 一个页面，或整个站点 |
| 页面入口 | `components.html` | `templates.html` |
| 典型用途 | 卡片、价格表、导航条、表单片段 | 营销首页、文档页、整站骨架 |
| 插入方式 | Builder 左侧「组件库」→「插入」 | Builder 左侧「模板库」→「套用」；或模板库页面「套用模板」 |
| 能带走自定义组件 | 组件本身就是组件 | 会带走模板页面引用到的组件 |

一句话区分：

- **组件 = 页面里的一个零件**，插入后是一个区块；
- **模板 = 一个或多个完整页面**，套用后生成页面。

---

## 二、组件库页面导览

打开 `components.html` 后，界面分三块：

- 顶部：返回工作台、站点下拉、返回 Builder、模板库、数据源、导出；
- 左侧：组件列表、回收站、「从 JSON 导入」；
- 右侧：选中组件后的编辑器，包括基本信息、字段、三件套、作用域说明、使用情况，以及右侧的实时预览。

左侧列表的计数会显示成：

```text
N 自定义 · N 内置
```

- **自定义组件**：可以改、可以复制、可以导出、可以删除；
- **内置组件**：只读，不能直接改，但可以「复制为自定义」后再改。

列表上方有搜索框（按名称 / ID / 标签）和两个筛选下拉（类别、标签）。

左下角写明了硬限制：

- 单组件最多 **40 个字段**；
- HTML 模板最大 **256 KB**。

## 三、从零做一个自定义组件

### 第 1 步：点「新建组件」

左侧列表上方的「新建组件」。点击后会得到一个预填的草稿：

- 一个字段 `title`（名称「标题」，类型文本，必填，默认值「示例标题」）；
- 一段 HTML 示例，里面用 `{{title}}` 取值；
- 一段基础 CSS；
- 空的 JS。

同时右侧预览会立刻显示效果。

### 第 2 步：填「基本信息」

| 字段 | 怎么填 | 说明 |
| --- | --- | --- |
| 名称 | 例如「价格卡」 | 必填，最多 64 字 |
| 组件 ID | 例如 `price-card` | 新建时会跟随名称自动生成；创建保存后不可再改 |
| 类别 | 从下拉选 | 用于左侧筛选 |
| 图标 | 从下拉选 | 只影响列表展示 |
| 标签 | 逗号分隔，最多 8 个 | 用于搜索和筛选 |
| 说明 | 可留空 | 最多 512 字 |

> 组件 ID 会写进页面引用和导出包。创建后不可修改，起名时想清楚。名称可以随时改。

### 第 3 步：加「字段」

点「添加字段」，每行需要填：

- `名称`：显示给使用者看的标签；
- `ID（占位符）`：HTML 里用 `{{这个ID}}` 取值，建议小写英文/数字/连字符；
- `类型`：文本、数字、布尔、枚举等；
- `必填`：勾选后插入时会提示；
- `默认值`：可留空；
- `枚举选项`：只有类型为枚举时出现，逗号分隔。

字段行右侧的 `×` 可以删除该字段。

### 第 4 步：写「三件套」

「三件套」有三个标签页：

- `HTML`：组件的结构模板，用 `{{字段ID}}` 插入字段值；
- `CSS`：组件样式，保存时不需要你手写作用域前缀；
- `JS`：组件脚本，每个实例独立执行。

### 第 5 步：看「实时预览」

右侧「实时预览」会用「样例数据」渲染你的组件：

- 上方可切「亮」「暗」两种预览模式；
- 「样例数据」区按字段生成输入控件，改一下就能看到不同内容；
- 脚本报错时，预览标题旁会出现「脚本错误」，下方列出错误信息。

预览是在沙箱 iframe 里跑的，不会影响编辑器本身。

### 第 6 步：点「保存组件」

保存时服务端会做校验：

- 组件名称不能为空；
- HTML / CSS / JS 语法错误会拦截，并定位到行号，自动切到出错标签页；
- 禁止 `document.write` / `document.writeln` 和 `innerHTML` 拼接；
- 如果改动涉及字段的破坏性变化，会返回「字段改动会影响这些页面」，列出受影响的页面，需要你确认后才保存。

保存成功后，左侧列表出现该组件，Builder 的「组件库」标签里也能插入它。

## 四、组件作用域：为什么不会污染页面

组件库页面的「作用域说明」写得很清楚，这里翻译成操作语言：

### CSS

- 你写的每个选择器都会自动加上组件前缀，形如：

```css
[data-lc-comp="price-card"] .price { ... }
```

- 你写的 `:root`、`html`、`body` 会被映射到**组件根节点**，不会改整页背景或全局字体；
- `@import` 会被丢弃；
- `@keyframes` 名称不改，动画名仍可能和页面里的重名。给自己的动画起独特名字最稳。

所以你不需要、也不应该自己写 `[data-lc-comp="..."]` 前缀。

### JS

- 每段 JS 都包在独立的 IIFE 中执行；
- `root` 指向当前实例根节点，用它查找元素最稳；
- 不要写 `window.xxx = ...` 这类全局赋值，多个实例会互相覆盖；
- 禁止 `document.write` / `document.writeln` 与 `innerHTML` 拼接。

### 实例隔离

同一个组件插入多次时：

- 每个实例有自己的 DOM 根；
- CSS 前缀相同，但作用域限定在各自根节点内；
- JS 每次执行是独立作用域，实例之间不共享变量。

## 五、使用情况、复制、删除与回收站

### 使用情况

选中自定义组件后，编辑器下方会显示它被哪些页面引用：

```text
被 3 个页面使用，共 5 次
产品介绍  product-intro.html · 2 次
活动页    campaign.html · 3 次
```

没有被引用时显示「当前没有被任何页面引用；删除会进回收站，可恢复」。

### 复制

- 内置组件：按钮文案是「复制为自定义」，复制出一份可编辑的自定义组件；
- 自定义组件：按钮是「复制一份」，得到同内容的新组件，ID 会自动调整。

### 删除

点「删除」不会立刻永久删除，而是：

1. 弹出确认，说明会移入回收站；
2. 确认后组件进入左侧「回收站」；
3. 回收站里可以随时恢复；
4. 恢复时如果 ID 或名称冲突，会自动生成新的副本。

如果组件正被页面引用，删除前会提示影响范围。建议先看「使用情况」，再决定是否删除。

## 六、组件导入导出

### 导出

选中组件后点工具栏「导出 JSON」，浏览器会下载一个 JSON 文件。这个文件包含组件的字段、HTML、CSS、JS 和元信息，可以用来备份或发给别人。

### 导入

组件库页面左侧底部有「从 JSON 导入」，点击后选择 `.json` 文件。导入成功后：

- 组件出现在列表里；
- 如果 ID 或名称冲突，会自动调整，并在提示里说明；
- 导入不会覆盖已有组件。

### 在 Builder 里拖拽导入（支持多文件）

进入 Builder，左侧切到「组件库」标签，最上方有一个虚线框：

```text
拖入组件文件
.component.json · 支持多文件 · 单个 ≤ 512 KB
```

操作：

1. 从文件管理器把 `.component.json` 文件拖到这个虚线框；
2. 或点旁边的「选择文件」，一次选多个；
3. 下方会显示导入进度和逐文件结果（成功 / 失败 / 提示）；
4. 导入完成后，组件出现在下方「组件库」列表，可直接「插入」。

注意：

- 单个文件不能超过 512 KB；
- 不要求文件名后缀一定是 `.component.json`，但内容必须是合法的组件 JSON；
- 拖拽区只在 Builder 的「组件库」标签里有；组件库页面本身用「从 JSON 导入」按钮。

## 七、模板库页面导览

打开 `templates.html` 后，界面结构：

- 顶部：返回工作台、站点下拉、返回 Builder、组件库、数据源、导出；
- 左侧：模板列表、回收站、「从 JSON 导入」；
- 右侧：起步模板、创建面板、选中模板后的基本信息与「内容结构」，以及「套用模板」卡片和「模板边界」说明。

左侧顶部有两个创建按钮：

- `页面存为模板`
- `整站存为模板`

列表上方显示模板总数，支持按名称 / 说明 / 标签搜索，以及按类型（页面模板 / 站点模板）、分类、标签筛选。

限制：

- 模板名称 ≤ 64 字；
- 标签 ≤ 8 个。

---

## 八、把页面存成模板

### 第 1 步：点「页面存为模板」

右侧出现创建面板，标题是「把页面存为模板」，说明写着：

> 只保存这个页面的内容、布局与引用到的自定义组件。

### 第 2 步：选「源页面」

下拉里列出当前站点的所有页面，格式为：

```text
产品介绍 · product-intro.html
```

站点还没有页面时，下拉显示「当前站点还没有页面」，无法创建。

### 第 3 步：填模板信息

- `模板名称`：必填，默认取源页面标题；
- `分类`：下拉选择；
- `标签`：逗号分隔；
- `描述`：一句话说明用途。

### 第 4 步：点「创建模板」

成功后：

- 右侧切到该模板的详情；
- 左侧列表出现新模板；
- 「内容结构」会列出模板包含的页面和引用到的自定义组件。

页面模板**不会**包含：

- 数据源配置；
- 接口密钥；
- 导出配置；
- 后端配置。

---

## 九、整站存为模板

点「整站存为模板」，创建面板标题变成「把整个站点存为模板」，说明写着：

> 会带走全部页面、组件、主题、导航与页脚；数据源与密钥不会进模板。

需要填的信息与页面模板相同，但没有「源页面」下拉，因为默认打包整个站点。

整站模板包含：

- 全部页面；
- 全部自定义组件；
- 主题；
- 导航与页脚配置。

整站模板**不包含**：

- 数据源；
- 接口密钥；
- 导出配置；
- 后端配置。

## 十、套用模板

选中任意模板后，右侧有「套用模板」卡片，有两种方式：

### 方式一：新建页面（默认）

1. 选择「新建页面」；
2. 可填写 `页面标题`、`页面 ID / Slug`、`输出路径`；
3. 留空就沿用模板默认值；
4. 点「套用模板」。

结果是新增页面，不会动现有页面。

### 方式二：覆盖现有页面

1. 切换到「覆盖现有页面」；
2. 在「覆盖到页面」下拉里选目标页面；
3. 点「套用模板」；
4. 出现二次确认，说明将覆盖哪个页面；
5. 点「确认覆盖」才真正执行。

覆盖规则：

- 把目标页面的区块与布局替换成模板内容；
- **原内容会先备份**；
- 页面 ID、路径保持不变；
- 取消确认不会做任何改动。

### 同时套用导航与页脚

站点模板的套用面板里会出现一个复选框：

```text
同时套用导航与页脚（会覆盖当前站点的导航与页脚）
```

勾选后会一并替换站点的导航与页脚配置；页面模板没有这个选项。

### 缺少组件时

套用模板如果引用了当前站点没有的自定义组件：

- 只会**补齐缺失项**；
- **不会覆盖已有同名组件**；
- 结果提示里会分别列出「补齐组件」和「跳过已存在组件」。

### 起步模板

模板库页面顶部还有「起步模板」区域，列出四套完整骨架：文档站、落地页、后台仪表盘、认证中心。点套用前会确认：

> 套用「xxx」会新建 N 个页面，并替换当前站点的导航、页脚与侧栏。继续？

起步模板与新建项目时选的模板是同一套数据，区别只是这里可以给已有站点再套一次。

## 十一、模板的导入导出与回收站

### 导出

选中模板后点工具栏「导出 JSON」，下载模板文件。文件需要带：

```json
"format": "lowcode-template"
```

缺少这个标识的文件，导入时可能被拒绝或提示格式不符。

### 导入

左侧底部「从 JSON 导入」，选择 `.json` 文件。导入成功后提示里会列出需要注意的事项（例如 ID 调整、组件补齐情况）。

### 在 Builder 里拖拽导入

Builder 左侧「模板库」标签最上方同样有虚线框：

```text
拖入模板文件
.template.json · 支持多文件 · 单个 ≤ 512 KB
```

支持一次拖入多个模板文件，下方显示进度和逐文件结果。导入后出现在「模板库」列表，可直接「套用」。

### 删除与恢复

删除模板会进入左侧回收站，可随时恢复；恢复时如果 ID 或名称冲突，会自动改名。

## 十二、常见问题

### 1. 内置组件为什么改不了？

内置组件是只读的，避免误改影响所有站点。要改就点「复制为自定义」，得到一份独立副本后再编辑。

如果只是想在**某一个页面里**改这一个实例的结构，不需要复制整个组件，直接在该实例的「实例级代码覆盖」里改 HTML / CSS / JS 即可。详见第 03 章。

### 2. 组件插入后字段是空的，正常吗？

正常。自定义组件插入页面时，字段默认都是空值，需要你在属性面板里逐个填。组件本身的「默认值」只在组件库预览里用作样例，不会自动带进每个实例。

### 3. 改了组件字段，已有页面会坏吗？

服务端会先列出受影响的页面，让你确认后才保存。确认保存后，这些页面会按新字段结构渲染，原有的同名字段值保留。改动前先看「使用情况」。

### 4. 模板套用后能撤销吗？

页面级的覆盖会先备份原内容，但界面上没有「一键回滚模板套用」按钮。稳妥做法是覆盖前先导出模板或备份站点（见第 11 章），不要依赖临时记忆。

### 5. 为什么从 JSON 导入后 ID 变了？

导入时如果 ID 或名称与现有内容冲突，会自动调整以避免覆盖。提示里会说明调整结果。

### 6. 拖拽导入没反应？

检查：

- 是否在 Builder 左侧「组件库」或「模板库」标签的虚线框里放下；
- 文件是否超过 512 KB；
- 文件内容是否是合法 JSON，且模板带 `format: "lowcode-template"`；
- 浏览器是否拦截了多文件拖放。

组件库页面和模板库页面本身没有拖拽区，请用「从 JSON 导入」。
