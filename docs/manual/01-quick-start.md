# 01 快速开始：从启动到第一个页面

> 本篇目标：把一个纯静态项目建出来，在首页上放下标题、正文和按钮，保存并确认改动已经落盘。
>
> 读完本篇，你应该能独立完成：启动服务 → 打开工作台 → 新建项目 → 进入 Builder → 插入区块 → 改属性 → 保存。

---

## 一、开始前准备

### 1. 确认 Node 版本

平台需要 Node 20。打开 PowerShell，执行：

```powershell
node -v
```

看到 `v20.x.x` 或更高版本即可。低于 20 时，先安装 Node 20 LTS，再重开终端确认。

### 2. 确认工作目录

本手册中的命令都在平台根目录执行：

```powershell
cd C:\project\docs\lowcode
```

如果你把平台放在别的路径，把上面的路径换成你自己的。后面提到的 `data/`、`logs/`、`scripts/` 都相对这个根目录。

---

## 二、启动服务

有两种启动方式，效果一样，任选一种。

### 方式 A：Windows 双击启动（推荐给第一次使用的人）

在文件资源管理器里进入平台根目录，双击 `start.cmd`。

会弹出一个命令行窗口，依次做这几件事：

1. 检查 Node 版本；
2. 首次启动或依赖有更新时，自动执行依赖安装；
3. 读取 `platform.config.json`；
4. 检查端口，被占用时自动换一个可用端口；
5. 启动服务，并自动打开浏览器。

窗口不要关。关掉窗口等于停止服务。

### 方式 B：命令行启动

```powershell
npm start
```

第一次运行如果提示正在安装依赖，等它装完即可。安装期间不要重复按回车或重复启动。

### 启动成功的标志

终端会打印类似内容：

```text
  低代码工作台 已启动
  地址：http://127.0.0.1:9780/
  数据：data/sites（相对平台根）
  停止：Ctrl+C
```

浏览器通常会自动打开 `http://127.0.0.1:9780/`。如果没自动打开，手动在地址栏输入终端打印的地址。

### 端口被占用时

终端会出现一行提示，类似「端口 9780 被占用，改用 9781」。这是正常回退，不是错误。**以终端打印的地址为准**，不要继续用 9780。

实际使用的端口也会写进 `logs/start-port.json`。

### 停止服务

在终端窗口按 `Ctrl+C`。看到「收到 SIGINT，正在关闭服务…」后窗口会退出。

### 启动失败时

先看终端最后几行，再按顺序检查：

1. Node 版本是否达到 20；
2. 是否在平台根目录执行命令；
3. `npm run doctor` 的自检结果；
4. `logs/boot-error.json` 里的失败原因。

更完整的排查流程在第 12 章。

## 三、认一下工作台首页

打开 `http://127.0.0.1:9780/`，看到的是**工作台**，不是编辑器。

页面结构如下：

- 顶栏左侧：品牌「低代码工作台」，副标题「项目 · 模板 · 导出」。
- 顶栏右侧：`模板库`、`组件库`、`数据源`、`中间件`、`配置中心`、`导出向导`、`主题`。
- 正文标题：「我的项目」，右侧有「新建项目」和「刷新」两个按钮。
- 正文下方：项目卡片列表。

第一次打开时没有项目，列表显示：

> 还没有项目。点右上角「新建项目」开始；也可以先去模板库看看。

有项目后，每张卡片显示：

- 项目名称（点击直接进 Builder）；
- 类型徽标：`纯静态`，或 `带后端 · Rust / Node / Go`；
- 最近修改时间；
- 页面数量；
- 底部两个入口：「进入编辑器」「导出」。

> 注意：这里的「导出」直接打开导出向导，不是立刻下载文件。导出流程在第 09 章。

---

## 四、新建第一个纯静态项目

### 第 1 步：点「新建项目」

在首页右上角点「新建项目」，弹出「新建项目」对话框。

### 第 2 步：填项目名称

在「项目名称」输入框里填写，例如：

```text
我的第一个站点
```

名称不能为空，最多 80 个字符。留空提交会提示「项目名称不能为空」。

### 第 3 步：确认项目类型

「项目类型」默认选中「纯静态」，保持默认即可。

另一项「带后端」会在下面多出一个「后端语言」下拉框。本篇先不选它，两种类型的区别放到第 02 章。

### 第 4 步：起步模板选「空白站点」

「起步模板」下拉框默认是「空白站点」，保持默认。

如果选四套起步模板中的任意一套，创建后会直接得到一套完整页面。第一次练习建议先用空白站点，从零放一个区块，理解编辑器的基本操作。

### 第 5 步：点「创建并进入编辑器」

按钮在对话框右下角，文案是「创建并进入编辑器」。

点下后按钮会短暂变成「创建中…」，然后浏览器跳转到：

```text
builder.html?site=<你的站点ID>
```

创建失败时，对话框内会出现红色错误文字，按钮恢复可点。常见原因是名称为空，或本地数据目录不可写。

## 五、第一次进入 Builder：先认布局

Builder 是建站编辑器。不要急着点，先看清四个区域。

### 1. 顶栏

从左到右：

- 「工作台 ←」：点它回项目列表；
- 视口切换：`桌面`、`平板 820`、`手机 420`；
- 「站点」下拉框：当前项目；
- 保存状态徽标：`已保存`、`未保存`、`保存中…`、`保存失败`；
- 功能按钮：`数据`、`组件库`、`模板库`、`主题`、`主题编辑器`、`中间件`、`配置中心`；
- `撤销`、`重做`；
- `导出`、`保存`。

纯静态项目不会显示「后端代码」按钮。窗口较窄时，部分按钮会收进「更多 ▾」菜单。

### 2. 左侧资源栏

顶部有三个标签：

- 「页面」：页面列表、图层树、页面文件导入；
- 「组件库」：内置区块、自定义组件、组件文件导入；
- 「模板库」：页面模板、整站模板、模板文件导入。

新建项目后，「页面」标签下已经有一个页面：

```text
首页    index.html
```

它默认被打开并显示在画布中。

### 3. 中间画布

画布上方工具栏写着「正在编辑」，右边是页面标题输入框、页面路径、`N 个区块`，以及「重新加载」。

画布本身是实时渲染的，没有单独的「预览」按钮。

### 4. 右侧属性面板

标题默认是「页面属性」。选中某个区块后，标题会变成区块名称，下面按字段列出可编辑项。

底部状态栏会显示：

- 页面文件路径；
- 「已与磁盘同步」或「有未保存改动（草稿已留存）」。

## 六、放下第一个区块

空白首页没有内容，图层树会提示：

> 当前页还没有区块。到「组件库」点「插入」，或先导入一个页面。

下面按顺序做一个最小页面。

### 第 1 步：打开「组件库」标签

点左侧资源栏顶部的「组件库」。

会看到两个区域：

- 「内置区块」：平台自带的基础区块，空白项目也能直接用；
- 「组件库」：当前站点自己的组件，新建空白项目时是空的。

### 第 2 步：插入「标题」

在「内置区块」列表里找到「标题」，点它右侧的「插入」。

插入后会发生三件事：

1. 左侧自动切回「页面」标签；
2. 画布出现这个区块；
3. 右侧属性面板标题变成「标题」，并显示两个字段。

### 第 3 步：在属性面板填内容

右侧属性面板里：

- 「标题文字」：填 `欢迎来到我的第一个站点`；
- 「标题级别」：可选 `H2 · 章节标题` 或 `H3 · 小节标题`，先用默认的 H2。

输入过程中画布会跟着更新。标题文字为空时，画布上可能看不到文字，但图层树里依然有这一项，选中它即可继续填。

### 第 4 步：再插入「段落」

回到「组件库」标签，在内置区块里找到「段落」，点「插入」。

右侧属性面板会出现「正文（支持 Markdown）」。填入：

```markdown
这是用低代码平台搭出来的第一个页面。

- 左侧是页面与图层
- 中间是画布
- 右侧是属性面板
```

段落支持 Markdown，列表、标题、链接、代码块都可以直接写。

### 第 5 步：插入「按钮」

再次回到「组件库」，找到「按钮」，点「插入」。

右侧属性面板有三个字段：

- 「按钮文字」：填 `了解更多`；
- 「链接地址」：先填 `#`，作为占位；
- 「样式」：`实心` 或 `描边`，任选；
- 「对齐」：`靠左`、`居中`、`靠右`。

### 插入位置的规则

- 当前**选中了一个容器**：新区块会放进这个容器里；
- 当前**没有选中容器**：新区块追加到页面末尾；
- 想调整顺序，在左侧「图层树」里拖动条目；拖到容器中间会嵌套进去，拖到条目之间会改变顺序。

## 七、保存与确认

### 自动保存

改完属性后，Builder 会在约 1.2 秒后自动保存。顶栏徽标会短暂显示「保存中…」，成功后回到「已保存」。

### 手动保存

想立刻保存，点顶栏「保存」，或按 `Ctrl+S`。

「保存」按钮在没有改动时是灰的，这是正常的。

### 确认改动真的落盘

做下面任意一件事：

1. 左侧底部状态显示「已与磁盘同步」；
2. 点工具栏「重新加载」，页面从磁盘重新读一遍，内容仍在；
3. 按浏览器刷新键，重新进入同一个 `builder.html?site=...` 地址，内容仍在。

如果刷新后内容消失，说明保存失败。先看顶栏徽标是否为「保存失败」，再按第 12 章排查。

---

## 八、换三档视口看看

顶栏的 `桌面`、`平板 820`、`手机 420` 只改变画布宽度，不改变页面数据，也不会触发保存。

- `桌面`：默认宽度，适合检查多栏布局；
- `平板 820`：检查中等宽度下卡片、导航是否拥挤；
- `手机 420`：检查窄屏下的换行和按钮宽度。

注意：这里的视口是**画布预览宽度**，不是浏览器窗口宽度。用真正的手机访问导出产物时，效果仍受页面自身响应式规则影响。

---

## 九、撤销、重做与重新加载

- 「撤销」：回退一步结构或属性改动，快捷键 `Ctrl+Z`；
- 「重做」：恢复刚撤销的改动，快捷键 `Ctrl+Shift+Z`；
- 「重新加载」：丢弃内存里的当前页，从磁盘重新读取。

「重新加载」不是「刷新浏览器」，它只重载当前页面文件。有未保存改动时先保存，或确认确实要丢弃。

---

## 十、回到工作台

点顶栏左侧「工作台 ←」。

首页项目列表中会出现你刚建的项目卡片：

- 类型：`纯静态`；
- 页面数：`1 个页面`；
- 最近修改：刚刚。

点卡片标题或「进入编辑器」可以再次打开。

## 常见卡点

| 现象 | 先检查什么 |
| --- | --- |
| 双击 `start.cmd` 后窗口闪退 | 是否装了 Node 20；在 PowerShell 里执行 `node -v`；再运行 `npm run doctor` |
| 浏览器没自动打开 | 看终端打印的地址，手动打开；可能端口不是 9780 |
| 首页提示「项目加载失败」 | 服务是否还在运行；终端是否有报错；`logs/` 里是否有异常 |
| 点了「新建项目」但没弹窗 | 是否点到了顶栏其他入口；刷新首页重试 |
| 画布一片空白 | 当前页是否真的选中；左侧页面列表是否高亮；空白页本来就没有区块 |
| 内置区块列表为空 | 站点信息没加载完，点「组件库」标签切换一次；仍为空就刷新页面 |
| 属性面板没有字段 | 没有选中区块；先在画布或图层树里点一下区块 |
| 「保存」按钮是灰的 | 当前没有改动，属于正常状态 |
| 顶栏显示「保存失败」 | 看底部状态栏和终端；数据目录是否可写；按第 12 章排查 |
