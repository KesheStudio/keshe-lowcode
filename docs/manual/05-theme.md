# 05 主题：改令牌、保存到站点与亮暗色

> 本篇目标：分清 Builder 顶栏的「主题」按钮和「主题编辑器」；会用主题编辑器改颜色令牌、保存到站点；理解亮色 / 暗色如何生效，以及导出时哪些主题会被带走。
>
> 主题只影响颜色与外观，不改变页面结构和内容。页面怎么搭见第 03 章，导出细节见第 09 章。

---

## 一、两个入口，别点混

Builder 顶栏有两个和主题有关的入口：

| 入口 | 文案 | 打开什么 | 适合做什么 |
| --- | --- | --- | --- |
| `主题` 按钮 | 主题 | 一个小弹窗「站点主题」 | 快速选当前主题、设明暗、勾选允许访客切换的主题 |
| `主题编辑器` 链接 | 主题编辑器 | 独立的主题编辑器页面 `theme/editor.html` | 改令牌、调色、看对比度、导入导出主题 JSON |

工作台顶栏也有一个「主题」链接，直接打开主题编辑器。

一句话：**换一套现成主题用「主题」按钮；改颜色本身用「主题编辑器」。**

---

## 二、用「主题」按钮快速换主题

### 第 1 步：点 Builder 顶栏「主题」

弹出「站点主题」对话框，包含三块：

1. `当前主题`：列出可选主题，每项显示名称和来源（内置 / 站点自定义）；
2. `允许访客切换`：一组复选框；
3. 顶部的 `明暗` 下拉和 `保存` / `取消` / `关闭` 按钮。

### 第 2 步：选「当前主题」

点某一项的单选按钮。选中项会高亮。

### 第 3 步：设「明暗」

下拉只有三个值：

```text
跟随系统
亮色
暗色
```

它决定站点默认外观，不是编辑器的外观。

### 第 4 步：勾选「允许访客切换」

这里勾选的主题，才会在导出产物里生成对应的 CSS，访客才能切过去。

规则：

- 当前主题始终包含，且它的复选框被锁定，不能取消；
- 未勾选的主题不会进入导出产物的 CSS；
- 勾选越多，产物 CSS 越大。只勾真正要提供的几套。

### 第 5 步：点「保存」

成功后提示：

> 主题已保存，画布与导出都会使用这套设置

画布会立即按新主题重绘。

---

## 三、打开主题编辑器

从 Builder 顶栏点「主题编辑器」，或从工作台顶栏点「主题」。

进入后是独立页面，布局分三块：

- 左侧：主题列表；
- 中间：色板编辑；
- 右侧：亮色 / 暗色并排实时预览。

### 顶部操作栏

| 控件 | 作用 |
| --- | --- |
| `新建` | 从空白主题开始 |
| `复制` | 复制当前主题为副本 |
| `保存`（文案会变） | 有站点时是「保存到站点」，无站点时是「保存草稿」 |
| `导出 JSON` | 下载当前主题文件 |
| `导入` | 选择主题 JSON 文件载入 |
| `站点默认外观` | 跟随系统 / 亮色 / 暗色，只在站点模式出现 |
| `编辑器外观` | 跟随主题 / 强制亮色 / 强制暗色，只影响编辑器自身 |
| `返回工作台` | 回工作台 |

顶部还会显示当前保存状态，例如：

```text
站点主题 · 有未保存改动
内置主题 · 改动会另存为草稿
草稿 · 已保存
```

### 左侧主题列表

主题分三类来源：

- **内置**：平台自带的 10 套主题，只读；
- **站点**：已经保存到当前站点的自定义主题；
- **草稿**：存在浏览器本地的「我的主题」。

内置主题改动后不会直接改掉内置文件，会另存为草稿或站点主题。列表底部有拖放区：

```text
把导出的主题 JSON 拖到这里
或点顶栏「导入」。不合格也会载入，并逐条列出问题。
```

### 没有站点时也能用

如果打开时没有关联站点，编辑器会退化为本地草稿模式：

- 保存按钮文案是「保存草稿」；
- 主题存在浏览器本地；
- 可以导出 JSON 带走，但不会写进任何站点。

所以看到「保存草稿」而不是「保存到站点」，先检查站点是否选中。

## 四、改令牌：从主色到派生色

中间「色板」区按顺序是：

1. 亮色 / 暗色标签；
2. 主题信息；
3. 主色（种子）；
4. 派生色（自动计算，可逐项覆盖）；
5. 实时校验。

### 第 1 步：选「亮色」或「暗色」

两个标签分别编辑同一套主题的两种模式。两套都要改，不能只改亮色就交付。

### 第 2 步：填「主题信息」

| 字段 | 规则 |
| --- | --- |
| `id` | 小写字母 / 数字 / 连字符；保存到站点时会做规范化，冲突会自动加 `-2` |
| `名称` | 显示在主题列表和「主题」对话框里 |
| `调性` | 纸感 / 冷调 / 暖调 / 中性 / 高对比 / 工程蓝，用于分类展示 |
| `描述` | 一句话说明，显示在主题列表里 |

### 第 3 步：改「主色（种子）」

主色是主题的源头。当前版本有 11 个必填主色：

| 令牌 | 界面文案 | 影响 |
| --- | --- | --- |
| `bg` | 页面背景 | 整页底色 |
| `surface` | 卡片/面板背景 | 卡片、面板、输入框底色 |
| `ink` | 正文文字 | 主要文字颜色 |
| `muted` | 次要文字 | 说明、辅助信息 |
| `line` | 分隔线 | 边框、分隔线 |
| `accent` | 主色（强调色） | 按钮、链接、选中态 |
| `codeBg` | 代码底色 | 代码块背景 |
| `success` | 成功色 | 成功提示 |
| `warn` | 警告色 | 警告提示 |
| `danger` | 危险色 | 错误、删除 |
| `info` | 信息色 | 中性提示 |

另有一个可选主色：

| 令牌 | 界面文案 | 说明 |
| --- | --- | --- |
| `accent2` | 辅助强调色（可选） | 需要第二种强调色时才填，留空会自动处理 |

每个主色有两种填法：

- 用颜色选择器点选；
- 直接填十六进制值，例如 `#3e6a56`。

主色必须按**实色十六进制**保存。填了非法值会提示，派生色和对比度不会按坏值计算。

### 第 4 步：看「派生色」

派生色由主色自动计算，通常不需要手改。展开「派生色（自动计算，可逐项覆盖）」后可以：

- 查看自动算出的颜色令牌；
- 对不满意的项逐项覆盖；
- 清除覆盖，回到自动计算。

日常调主题建议只改主色，让派生色自动跟随，避免亮暗两套不一致。

### 第 5 步：看「实时校验」

校验会计算文字与背景的对比度。不达标时：

- 在「实时校验」里列出问题；
- 顶部状态变成有未保存改动；
- 点保存时会被拦下，提示「还有 N 个问题，修正后再保存」。

典型提示是正文对比度不足，需要「把正文调深或背景调浅」。不要忽略它：导出后用户看不清，问题只会更难发现。

### 第 6 步：看「实时预览」

右侧并排显示亮色和暗色两个预览面板，内容是一套真实的页面元素（标题、按钮、表单、表格、提示块）。顶部还会显示当前对比度数值，例如：

```text
亮色 正文 12.4:1 · 次要 5.2:1
```

改一个主色，两个预览都会立即更新。

## 五、保存到站点

### 第 1 步：确认顶部按钮是「保存到站点」

如果显示「保存草稿」，说明当前没有关联站点。回到 Builder 或工作台重新进入主题编辑器，确认站点已选中。

### 第 2 步：点「保存到站点」

保存前会先跑一遍校验。通过后：

- 主题写入 `data/sites/<站点ID>/themes/<主题ID>.json`；
- 站点的当前主题（`project.json` 里的 `theme.activeId`）指向这套主题；
- 这套主题会自动加进「允许访客切换」列表；
- 提示：

> 已保存到站点「站点名」，builder 与导出刷新即生效

### 第 3 步：回 Builder 验证

回到 Builder，画布应立刻或刷新后使用新令牌。导出产物也会读取同一份主题变量。

### ID 冲突会怎样

- 从内置主题原地改令牌保存，允许写同名站点主题覆盖；
- 与其它站点主题重名时，自动加 `-2`、`-3`；
- 提示里会说明「主题 id 调整为 xxx」。

### 保存草稿（无站点时）

点「保存草稿」会把主题存进浏览器的「我的主题」，不会写进站点。适合先做设计、之后再用「保存到站点」落到具体项目。

## 六、亮色、暗色与访客切换

### 三种「明暗」不要混

| 设置 | 位置 | 作用 |
| --- | --- | --- |
| 站点默认外观 | 主题编辑器顶部 / Builder「主题」弹窗的「明暗」 | 站点默认用亮色、暗色，还是跟随系统 |
| 访客可切换的主题 | Builder「主题」弹窗的「允许访客切换」 | 导出时带哪几套主题的 CSS |
| 编辑器外观 | 主题编辑器顶部的「编辑器外观」 | 只影响你当前看到的编辑界面 |

### 导出时发生什么

- 当前主题始终包含；
- 只有「允许访客切换」里勾选的主题才会写进产物 CSS；
- 未勾选的主题不会出现在导出产物里，访客无法切到；
- 访客切换只改根节点上的主题标记，不额外发请求，所以不会白闪。

### 默认外观怎么选

- `跟随系统`：访客系统是深色就显示暗色；
- `亮色` / `暗色`：固定为其中一种，不跟随系统。

如果站点以阅读为主，建议「跟随系统」；如果品牌色在暗色下对比度不稳，先固定亮色，等暗色令牌调好再放开。

## 七、主题的导入导出

### 导出

点顶部「导出 JSON」，下载当前主题文件。

- 如果主题还有校验问题，仍会导出，但提示「还有 N 个问题，对方导入时会看到清单」；
- 导出的是**单个主题**，不是整个站点。

### 导入

两种方式：

1. 点顶部「导入」，选择 `.json` 文件；
2. 把文件拖到左侧「把导出的主题 JSON 拖到这里」区域。

导入策略：

- **不会因为不合格而拒绝载入**：只要 JSON 能解析，就会进编辑器；
- 问题会逐条列在「实时校验 / 导入检查」里；
- 修好后再保存；
- 导入检查通过时提示「字段完整，对比度全部达标，可以直接保存」。

### 导入后保存到站点

导入的主题默认是「导入文件」状态，点「保存到站点」才会真正写入站点。保存时同样会先校验。

## 八、常见问题

### 1. 改了主题，为什么 Builder 没变？

按顺序检查：

- 是否点了「保存到站点」，而不是只改中间色板；
- 顶部状态是否还显示「有未保存改动」；
- Builder 是否还停在旧页面缓存，点画布工具栏「重新加载」；
- 站点下拉是否选错。

### 2. 为什么保存按钮是「保存草稿」？

说明主题编辑器没有关联到站点。从 Builder 或工作台重新进入，或检查链接是否带了站点参数。

### 3. 「允许访客切换」勾了很多主题，有影响吗？

有。每套主题都会增加导出 CSS 体积。只勾真正要提供的主题，通常 2～3 套足够。

### 4. 当前主题能取消勾选吗？

不能。当前主题对应的复选框是锁定的，并且保存时会自动补进允许列表。

### 5. 亮色改好了，暗色还要改吗？

要。亮色和暗色是两套独立令牌，校验也分别计算。只改亮色会导致暗色模式对比度不足。

### 6. 可以直接改内置主题文件吗？

不建议，也不必要。内置主题只读，改动会另存为草稿或站点主题。直接改平台文件会在升级时被覆盖。

### 7. 导出主题 JSON 后，别人怎么用？

对方在主题编辑器里「导入」或拖入 JSON，检查通过后「保存到站点」即可。主题不包含页面内容，也不包含数据源。
