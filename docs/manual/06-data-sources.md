# 06 数据源与接口：集合、外部接口与组件取值

> 本篇目标：会在数据源页面建集合、加字段、导入数据；会配一个外部 HTTP 接口并测试；知道页面组件能怎样拿到数据，以及哪些地方当前还没有自动打通。
>
> 数据源页面只负责“数据定义与数据本身”，不负责页面排版。页面怎么搭见第 03 章，后端流程怎么读数据见第 07 章。

---

## 一、数据源页面里有什么

打开 Builder 顶栏「数据」，或工作台顶栏「数据源」，进入 `data.html`。

左侧分四块：

| 区块 | 内容 | 说明 |
| --- | --- | --- |
| 集合 | 「新建集合」+ 集合列表 | 表单、表格、图表共用的数据结构 |
| 接口 | 「新建接口」+ 接口列表 | 自定义 HTTP 接口，可映射到集合或组件数据 |
| 站点设置 | 「上传目标」 | 所有拖拽上传组件的默认上传地址 |
| 底部 | 限制说明 | 单集合最多 50000 行；导入单文件 ≤ 5 MB |

顶栏有「站点」下拉。所有集合、接口、上传目标都挂在**当前站点**下，先确认站点没选错。

纯静态项目也会显示这一页，并有一行提示：

> 当前是纯静态项目：集合、接口与上传目标会随导出打进 web/data/ 快照，页面不依赖后端服务。

意思是：数据定义仍然可用，但产物里只有导出的快照，不会实时请求平台后端。

## 二、建一个集合

### 第 1 步：点「新建集合」

左侧「集合」标题下的按钮。列表顶部会展开一个小表单：`集合名称` 和「取消」「创建」。

### 第 2 步：填名称并点「创建」

例如：

```text
商品
```

创建成功后，右侧进入集合编辑器，左侧列表出现该集合。

### 第 3 步：填「基本信息」

| 字段 | 说明 |
| --- | --- |
| 名称 | 可随时改，显示用 |
| 集合 ID | 创建后只读，写进页面绑定与导出快照，不能改 |
| 说明 | 可留空，最多 512 字 |

集合 ID 为什么不能改：已有页面引用和导出快照都用它，改名会让引用失效。

### 第 4 步：加「字段」

点「字段」卡片右上角「添加字段」。每个字段一行，需要填：

| 控件 | 说明 |
| --- | --- |
| 字段名 | 显示用，例如「商品名称」 |
| 字段 ID | 程序里用的键，例如 `title` |
| 类型 | 见下表 |
| 必填 | 勾选后写入行时必须提供 |
| 唯一 | 勾选后等同单列唯一索引，重复值会被拒 |
| 删除 | 移除该字段 |

支持 7 种字段类型：

| 类型 | 存什么 |
| --- | --- |
| 文本 | 字符串 |
| 数字 | 整数或小数 |
| 布尔 | true / false |
| 日期 | 日期或日期时间 |
| 枚举 | 限定在「可选值」里的字符串 |
| 引用 | 指向另一个集合的行 |
| JSON | 对象或数组 |

补充：

- 枚举字段要填「可选值」，逗号分隔；默认值会归一到第一个合法值；
- 引用字段要填「引用的集合」和「引用字段」，可留空；
- JSON 字段存对象或数组。

字段行下方可能出现额外输入（枚举可选值、引用目标等），按提示填即可。

### 第 5 步：配「索引与唯一约束」

「索引与唯一约束」卡片可以加多列组合索引：

- 点「添加索引」新增一行；
- 填索引名称；
- 勾选参与该索引的字段；
- 需要唯一时勾「唯一索引」；
- 字段级「唯一」已经自动生效，不需要重复加单列索引。

保存前会做唯一性检查。已有数据违反新约束时，保存会被拒绝并指出冲突。

### 第 6 步：点「保存字段与索引」

按钮在右侧工具栏。字段类型一旦被页面组件引用，改类型前会先返回影响清单，需要你确认后才保存。

## 三、往集合里放数据

集合编辑器下半部分是「数据行」。

### 手动新增

1. 点「新增一行」；
2. 在展开的行表单里按字段填写；
3. 保存后表格里出现新行。

### 生成示例数据

1. 在「示例条数」里填 1～100，默认 10；
2. 点「生成示例数据」；
3. 提示会说明新增几行、因唯一约束跳过几行。

示例数据只是占位值，正式使用前记得清掉或替换。

### 搜索与分页

- 搜索框「搜索任意字段」，输入即按关键字过滤；
- 每页最多显示 100 行；
- 翻页由表格底部的分页控件控制。

### 编辑与删除

每行右侧有编辑、删除操作。删除不可撤销，删前确认。

### 单集合上限

单集合最多 **50000 行**。超过后写入会被拒绝，需要拆集合或清理旧数据。

## 四、导入 CSV / JSON

### 第 1 步：点「导入数据」

按钮在集合工具栏。进入「导入到 <集合名>」页面。

### 第 2 步：选择文件

- 支持 `.csv` 和 `.json`；
- 单文件上限 **5 MB**，单次上限 **2 万行**，超过会明确拒绝并给出实际大小；
- 文件在浏览器内读取后发给本机服务，不经过网络；
- 「格式」下拉可以选「自动识别」「CSV」「JSON」。类型先按扩展名判断，未知扩展名会自动识别。

### 第 3 步：做「列映射」

读取成功后出现「列映射与预览」：

- 每一行是一个文件列；
- 显示推断类型和样例值；
- 「导入到字段」下拉选择目标字段，或选「不导入」；
- 至少要把一列映射到集合字段，否则会提示「至少需要把一列映射到集合字段」。

### 第 4 步：选「冲突策略」

三选一：

| 策略 | 行为 |
| --- | --- |
| 追加 | 冲突行跳过，其余新增 |
| 覆盖 | 按唯一键更新已有行，未匹配则新增 |
| 跳过重复 | 整行完全相同的记录不导入 |

### 第 5 步：点「执行导入」

完成后显示「导入结果」：

```text
导入 120 行，跳过 3 行，失败 0 行；当前集合共 135 行。
```

失败行会列出原因（类型不符、唯一冲突、缺必填等）。可以点「再导入一个文件」继续。

## 五、配一个外部 HTTP 接口

### 第 1 步：点「新建接口」

左侧「接口」标题下的按钮。右侧进入接口编辑器。

### 第 2 步：填「接口基本信息」

| 字段 | 说明 |
| --- | --- |
| 名称 | 显示用，最多 64 字 |
| 接口 ID | 创建后只读，用于引用 |
| 说明 | 可留空，最多 512 字 |

顶部还有一行关键提示：

> 密钥（令牌 / 密码）不回显、不写进 sources.json、不进导出包与日志。

### 第 3 步：填「请求」

| 字段 | 说明 |
| --- | --- |
| 方法 | GET / POST / PUT / PATCH / DELETE 等 |
| 地址 | 只支持 `http` / `https` |
| 超时（毫秒） | 超过即失败，归类为「超时」 |
| 响应上限（字节） | 防止拉回超大响应 |
| Content-Type | 可留空，默认按 JSON 处理 |

地址限制：

- URL 里不能带账号密码；
- 本机数据库常见端口（3306 / 6379 等）一律拒绝；
- 不允许指向内网/本机敏感地址。

### 第 4 步：加「请求头」

点「添加请求头」，每行填：

- 键；
- 值；
- 是否勾选「密钥」。

勾选「密钥」的值只存本地密钥文件，界面上不回显，测试结果里也只显示「已填入（不回显）」或「未填写」。

### 第 5 步：加「查询参数」

点「添加查询参数」，同样支持「密钥」标记。用法与请求头一致。

### 第 6 步：写「请求体模板」

- `GET` / `HEAD` 不带请求体；
- 其它方法可以填 JSON 模板，例如：

```json
{"page": 1}
```

### 第 7 步：配「响应映射」

先选目标：

```text
映射到集合（返回数组可直接作为行数据）
映射到组件（字段结构供图表 / 表格使用）
```

然后填：

| 字段 | 说明 |
| --- | --- |
| 映射到集合 | 目标集合下拉 |
| 或映射到组件 | 填组件类型，例如 `table` / `chart` |
| 响应数组路径 | 例如 `data.items`；留空会自动识别 `data` / `rows` / `items` |

再点「添加映射」加字段映射：

- 响应字段 → 集合字段或组件字段；
- 留空时按同名字段匹配。

> 注意：这里的「映射到组件」只定义**字段结构**，供测试与导出使用。它**不会**自动把页面里某个区块的数据源名称改掉。页面组件的数据来源仍要在组件属性或实例配置里单独设置，见下一节。

### 第 8 步：点「测试连接」

「连接测试」会真实发一次请求，返回：

- 成功 / 失败徽标；
- 失败分类：成功、超时、网络、认证、HTTP 状态、格式、响应过大；
- 状态码与状态文本；
- 耗时（ms）；
- 响应大小与 Content-Type；
- 请求地址（密钥值不回显）；
- 解析到几行、用了哪个数组路径；
- 响应字段结构；
- 映射样例前几行；
- 未映射的响应字段。

失败时提示会说明是网络、认证还是格式问题。先修地址/密钥/字段路径，再测试。

### 第 9 步：点「保存接口」

保存成功后提示「接口已保存」。删除接口会二次确认，并说明本地保存的密钥会一起清除。

## 六、站点上传目标

左侧「站点设置」→「上传目标」，用于给所有拖拽上传组件提供默认值。

| 字段 | 说明 |
| --- | --- |
| 启用 | 启用 / 停用；停用后组件不再继承这里的配置 |
| 请求方法 | POST / PUT / PATCH |
| 上传地址 | 以 `/` 开头会拼在站点根下；也可填 `http(s)` 绝对地址 |
| 文件字段名 | 默认 `file` |
| 允许的文件类型 | 逗号分隔，例如 `image/*,.pdf,application/json`，可留空 |
| 单文件大小上限 | 字节，0 为不限 |
| 请求头 | JSON 对象，可留空 |

组件属性里单独填写时，以组件为准。

## 七、数据怎么到页面组件上

当前版本有三条真实可用的路径，也有一个容易误解的地方。

### 路径一：后端积木读集合，页面调接口

1. 在 `backend-flow.html` 里用「读取集合」节点读数据；
2. 用「返回 JSON」节点输出；
3. 在 Builder 选中区块，用「事件绑定」把事件接到这个接口；
4. 页面运行时请求接口并更新界面。

这条路径最完整，详见第 07 章。

### 路径二：自定义组件实例自己拉数据

选中一个自定义组件实例，属性面板会出现「实例数据来源」：

- 模式选「跟随组件/数据源默认」：与站点默认一致；
- 模式选「这个实例自己拉取」：填地址、方法、处理逻辑；
- 处理逻辑的入参是 `(payload, root)`，返回值作为实例数据；
- 数据到达后派发 `lc:instance-data`，可用 `data-lc-data-state` 观察 `loading / ready / error`；
- 浏览器端实现优先于站点后端默认实现。

这只对**自定义组件**实例出现。基础区块和 `ui-` 内置组件没有这个面板。

### 路径三：组件属性里的「数据源名称（平台注册）」

滑块、图表、统计卡、自动完成这几个内置组件支持从渲染运行时的数据源注册表取数。它们属性里有：

```text
数据源名称（平台注册）
```

这个名字对应 `LC.Render.registerDataSource(name, source)` 注册的键，**不是**数据源页面里随便一个接口 ID。当前版本的数据源页面没有「把接口注册成组件数据源」的入口。也就是说：

- 在数据源页面配好接口，不会自动让滑块出现远程取值；
- 要让组件按名称取数，需要站点运行时代码或自定义组件脚本里显式注册；
- 没有注册时，组件会明确提示，而不是假装有数据。

### 滑块的数据源行为（重点）

滑块（`ui-slider`）属性里有这些与数据源相关的字段：

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| 数据源名称（平台注册） | 空 | 填注册表里的名称 |
| 数据源取值方式 | `区间取值（min/max）` | 另一种是 `按档位取值（候选值）` |
| 数据源失败文本 | 数据源请求失败，请重试 | 请求失败时显示 |
| 数据源空结果文本 | 数据源没有可用取值 | 返回空数组时显示 |
| 数据源未注册文本 | 数据源尚未注册，已使用静态取值 | 名称没注册时显示 |
| 数据源加载中文本 | 正在加载数据源… | 请求期间显示 |

两种取值方式的实际行为：

**区间取值**

- 期望数据源给出 `{ min, max, step?, marks? }`；
- 或给出一个数值数组 / `items` / `values`，滑块取最小值和最大值作为边界；
- 拿到后会自动夹住当前值，并保持步长。

**按档位取值**

- 期望数据源给出 `stops` / `values` / `items` 数组；
- 每项可以是数字，也可以是 `{ value, label }`；
- 滑块内部按候选下标移动，显示的是候选值或标签；
- 排序后去重；非数字项会被忽略。

请求与状态：

- 加载中：显示「正在加载数据源…」，并临时禁用滑块；
- 成功且有值：应用新的区间或档位；
- **失败**（网络、超时、脚本异常）：显示失败文本，状态变为 `error`；
- **空结果**：显示空结果文本，状态变为 `empty`；
- **名称未注册或为空**：显示未注册文本，退回静态 `min` / `max` / `step`，滑块仍可用；
- 切换名称或取值方式会重新请求；旧请求会被取消，不会出现后到的旧结果覆盖新结果。

滑块还会派发两个事件：

```text
lc:slider-change   用户拖动或输入后触发，detail.value 是实际值
lc:slider-source   数据源应用后触发，detail 含 mode / min / max / step / stops / value
```

配置数据源文本时不要写得太技术化，面向最终用户写清楚“重试”“暂无数据”即可。

## 八、常见问题

### 1. 集合 ID 能改吗？

不能。它写进页面绑定与导出快照，改名会断引用。要“改名”只能新建集合并迁移数据。

### 2. 导入时提示超过 2 万行 / 5 MB 怎么办？

先拆分文件再分批导入。平台会明确拒绝并给出实际大小/行数，不会悄悄截断。

### 3. 测试连接成功，为什么页面还是没数据？

测试只验证接口本身。页面要拿到数据，还需要：

- 后端流程读取并返回；
- 或实例数据来源配好地址；
- 或组件数据源名称确实已注册。

三者都没有配置时，页面不会自动请求。

### 4. 为什么滑块显示「数据源尚未注册」？

你填的「数据源名称」不在渲染运行时注册表里。当前界面没有注册入口，需要运行时代码注册；不注册就按静态 min/max 使用，这是预期降级，不是页面坏了。

### 5. 接口里的密钥会进导出包吗？

不会。密钥只存本地密钥文件，`sources.json`、导出包和日志里都不出现明文。导出后的产物如果需要密钥，要在部署环境另行配置。

### 6. 纯静态项目配数据源有意义吗？

有。集合、接口、上传目标会作为快照打进 `web/data/`，前端可以读取快照；但不会有平台后端实时响应。需要实时读写时选带后端项目。

### 7. 「映射到组件」配好了，为什么页面没自动变？

它只定义字段结构，不会改页面区块属性。页面绑定仍要手动做，见第 03 章的事件绑定和第 07 章的后端流程。
