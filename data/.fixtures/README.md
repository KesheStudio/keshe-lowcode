# 回归测试样本（不要随手删除）

这里只保留当前格式（v2 站点目录）的固定样本，供导出管线与站点搬家脚本回归使用。
目录名以 `.` 开头是刻意标记：它们**不是**用户站点，服务不会把这里当作 `data/sites` 扫描。

## 内容

| 路径 | 类型 | 用途 |
| --- | --- | --- |
| `site-69fae0cc-e6e044c9/` | v2 站点目录 | 站点目录导入与导出回归；`assets/` 下有图片与 SVG |
| `site-69fae0cc-e6e044c9-export-regression/` | v2 站点目录 + 构建记录 | 服务端/CLI 导出回归样本；`builds/` 内保留了开启与关闭压缩的两次真实构建产物 |

站点目录里包含 `.lowcode/`（rev、锁、事务临时区）与 `backups/`，属于运行时痕迹，不影响读取。

## 使用方式

```powershell
# 同版本站点目录，预览
npm run migrate -- --from data/.fixtures/site-69fae0cc-e6e044c9 --dry-run
```

导入脚本按内容指纹判定幂等：同一样本重复导入应输出「已导入，跳过」，不会新建第二个站点。

## 维护约定

- 不要删除或改名，否则回归用例会失效。
- 需要更新样本时，新建目录并同步修改对应的测试用例，不要直接覆盖旧样本内容。
- 样本中不得放入私钥、证书密码或任何真实用户数据。
